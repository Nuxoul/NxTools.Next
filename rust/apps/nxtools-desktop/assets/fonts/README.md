- Upstream: https://github.com/be5invis/Sarasa-Gothic
- Distribution: SarasaUi-TTF-1.0.43.7z

The full copyright/license is also embedded in About's license view. Code/diagnostic monospace remains Consolas; explicit saved UI-family preferences remain authoritative.
