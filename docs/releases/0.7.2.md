# NxTools.Next 0.7.2

Windows x64 正式安装包。产品与浏览器扩展版本均为0.7.2，内部发布序号98。

## 更新内容

- Markdown阅读器支持代码、分栏和只读预览，统一字号控制，改进大纲导航与配置通知。
- 全局设置增加软件数据目录迁移和字体选择，新用户外观默认跟随系统。
- 改进Firefox下载接管、浏览器连接恢复和原始请求上下文处理。
- 优化首次文件索引的MFT元数据批读取、路径构造及持久化阶段。
- 更新归档、下载和快速启动的交互及生命周期处理。
