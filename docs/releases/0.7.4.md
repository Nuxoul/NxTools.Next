# NxTools.Next 0.7.4

Windows x64 正式安装包。产品与浏览器扩展版本均为0.7.4，内部发布序号101。

## 更新内容

- 关于窗口采用固定尺寸的非模态窗口，避免模态窗口关闭时对后台主窗口的禁用、恢复和强制激活；保留原复制、许可和更新检查入口。
- 应用黑名单选取窗口时临时隐藏本软件的可见顶层窗口，结束后恢复；原规则行的作用范围保留，仍由显式应用发布设置。
- 链接识别面板展开完整结果，短列表按内容高度显示，长列表使用可滚动区域，数量栏固定。
- 浏览器扩展弹窗聚焦页面资源、连接与接管状态，下载任务统一在桌面端管理。
- 产品、扩展和安装器版本统一为0.7.4，保持原发布身份、安装目录及用户数据。

## 安装与升级

下载`NxTools.Next-setup-0.7.4.exe`运行，无需先卸载。Bootstrap最低兼容门槛保持82。

需要 **Microsoft .NET 8 Desktop Runtime / Windows x64**（包含Core Runtime）。可从[微软官网](https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0)安装；单文件PlatformHost不自带运行时。

0.7.3可通过“关于 → 检查更新”识别更高的0.7.4版本。版本检测、下载安装器与执行安装是不同步骤；本版本不自动执行安装器。
