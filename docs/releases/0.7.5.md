# NxTools.Next 0.7.5

Windows x64 正式安装包。产品与浏览器扩展版本均为0.7.5，内部发布序号115。

## 更新内容

- 全应用新增 Solid / Acrylic 材质风格选择，与配色、深浅色和字体设置相互独立；旧配置缺少风格字段时保持 Solid。
- 外观设置提供窗口底色与内容层两项不透明度调节，默认72%/84%，下限60%，按统一表面矩阵生成各层实度。
- Acrylic 窗口使用系统圆角与匹配裁剪，Quick Launch 与剪贴板外壳保留各自圆角与模板。
- 窗口显示先保持实底90ms再过渡到磨砂；模块切换内容淡入一次，减少动态效果时只保留保持段。
- 主窗口无论隐藏准备或启动即显示均登记到材质运行时，成功回执前保持实底。
- 修复内容层透明度过高导致的设置侧栏、页脚与主窗口列表不透明问题；浅色下次要文字、分割线与卡片对比调整。
- 版本统一为0.7.5，保持原发布身份、安装目录及用户数据。

## 安装与升级

下载`NxTools.Next-setup-0.7.5.exe`运行，无需先卸载。Bootstrap最低兼容门槛保持82。

需要 **Microsoft .NET 8 Desktop Runtime / Windows x64**（包含Core Runtime）。可从[微软官网](https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0)安装；单文件PlatformHost不自带运行时。

0.7.4可通过“关于 → 检查更新”识别更高的0.7.5版本。版本检测、下载安装器与执行安装是不同步骤；本版本不自动执行安装器。
