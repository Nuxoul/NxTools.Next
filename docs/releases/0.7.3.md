# NxTools.Next 0.7.3

Windows x64 正式安装包。产品与浏览器扩展版本均为0.7.3，内部发布序号100。

## 更新内容

- 快速启动增加当前用户Windows已安装应用发现，支持系统应用的本地化名称和常用中英文别名，改进打包应用的Shell图标获取。
- 应用黑名单增加“选取窗口”，可从目标窗口填入进程名，仍由原设置页显式应用规则。
- 内置Sarasa UI SC Regular字体，新建或缺省字体配置使用该字体；保留用户明确保存的字体选择，不安装系统字体。
- 修复部分7z文件在目录打开阶段的资源限制误判，保留实际解码阶段的工作内存限制。
- Markdown大纲标题点击只导航，不再折叠其子项。
- 明确检查到更高Windows版本时，将对应安装器加入现有下载器；不自动执行安装。
- 改进快速启动、归档进度、链接面板和通知的多显示器定位及窗口复用。
- 增加功能开关与剪贴板临时暂停，改进下载窗口及浏览器接管的生命周期处理。
- 安装器增加Microsoft .NET 8桌面运行时检查，缺少依赖时提供明确提示和官方下载入口。

## 安装与升级

下载`NxTools.Next-setup-0.7.3.exe`后运行，沿用原安装目录和覆盖安装流程，无需先卸载。用户数据、AppId和发布信任保留，Bootstrap最低兼容门槛保持82。

需要 **Microsoft .NET 8 Desktop Runtime / Windows x64**（包含Core Runtime）。可从[微软官网](https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0)安装；单文件PlatformHost不自带运行时。

0.7.2可在“关于 → 检查更新”读取GitHub最新正式版本。已安装0.7.3不会将同版本安装包视为更高版本；版本检测、下载与安装是不同步骤。

## 已知限制

- 安装器没有Windows Authenticode证书签名；内部发布清单签名与Authenticode是不同机制。
- 本次使用`-SkipVerification`复用既有产品测试记录，未重跑全量Rust/C#集合。既有完整Desktop记录为2019通过、35失败、1忽略，后续相关功能定向检查通过；严格Clippy、部分格式和UI源规则尚未全部收敛。
- 未执行0.7.3真实覆盖安装、已安装索引服务验收、真实全局窗口选取/Shell图标、物理混合DPI界面或字体视觉验收、对应源码独立离线重构建。实际软件内更新检测及升级结果待用户验证。
