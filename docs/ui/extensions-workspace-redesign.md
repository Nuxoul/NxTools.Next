## 布局

```text
扩展                          [管理 ▾] [＋ 导入扩展]
已安装 6   待处理 2   调用记录
┌ 2 项需要处理：1 项待设置，1 项待信任 ── [查看待处理] ┐
[搜索名称、功能或关键词          ]   6 项 [所有使用位置 ▾]
┌ 剪贴板文本工具 ┐ ┌ 下载链接清单 ┐ ┌ GitHub 公开链接镜像 ┐
│ 做什么        │ │ 做什么      │ │ 做什么             │
│ 在哪用 · 可用 ›│ │ 在哪用…    │ │ 在哪用 · 待设置 ›  │
```

- **已安装**用于浏览。每格只保留名称、短用途、位置和状态，整个格子是一个进入详情的按钮。小窗保持两列，不缩小文字或把技术说明塞回格子。
- **待处理**用于配置、信任和恢复暂停的自动触发。结果最多指出一个当前阻塞和一个下一步；用户主动停用的扩展不算故障。按当前状态与搜索取交集。
- **调用记录**用于调查本次会话。执行中优先于已结束记录；终态按时间合并，区分手动与自动。失败可筛选：缺设置去设置，暂停去对应的自动触发，其他失败查看原因。无原始输入、无自动重试。
- **管理**收纳运行环境、下载解析链、插件目录及保留数据。导入是唯一页头主动作；管理仍有可见按钮边界。搜索、筛选和原目录滚动位置在关闭详情后保留。

## 关键流程

| 场景 | 呈现与动作 |
| --- | --- |
| 使用已安装扩展 | 打开格子进入同窗详情，默认页直接展示「在哪使用」和可做的事。剪贴板与下载动作仍从各自的条目菜单发起；详情不会猜测输入或执行。 |
| 缺少设置 | 详情显示缺项和「去设置」。从失败记录可以直接进入同一设置页；保存失败留在原字段，取消只放弃草稿。 |
| 未信任或环境不可用 | 进入独立信任确认，展示来源、运行环境、权限声明及固定风险说明；缺运行环境时提供已有环境设置入口，不能确认信任。信任成功回到详情，再由用户明确启用。 |
| 导入 ZIP | 系统选文件 → 检查 → 确认。新包导入后停用；相同内容只给关闭；同 ID 内容不同时说明版本和实际重置/保留项。失败给出原因和重新选择入口。 |
| 自动触发暂停 | 显示触发条件、最新失败和「恢复自动触发」；恢复仅等待新的事件。单独的订阅开关不随启用自动打开。 |
| 移除 | 独立确认，数据清除默认不勾选；涉及下载解析链时预告受影响的完整链。移除不删除本次会话已产生的调用记录。 |

详情右侧栏目标宽 420 DIP。内容按需滚动，标题和底部动作固定；同一侧栏切换「怎么用 / 设置 / 自动触发 / 来源」，只显示当前扩展支持的区域。未保存草稿继续由原设置所有者保管；关闭详情或切换标签不写入，取消才明确放弃当前草稿。剪贴板原条目内的进度和结果位置不变。

## GPUI Kit 0.8.0 实现映射

采用现有主题角色（原型以当前浅深配色为参考）、系统中文字体，间距 8/12/16/24 DIP。颜色不替代状态文字，不新增产品主题。

| 区域 | 已发布组件和组合 |
| --- | --- |
| 页头 | `Toolbar::content` 容纳实际按钮：导入 `Button::primary()`、管理 `Button::outline()`，显式 `Size::Medium`（32 DIP）。绝不改成 `Toolbar::child(Button)`，否则父组件会强制 ghost + compact。管理复用 `PopupMenu`。 |
| 主工作区 | `TabBar` / `Tab`；搜索 `Input` + icon prefix，复用原 `InputState`；位置 `Select`。格子使用 `ListItem::new` 的内容槽与 `Icon`/`Label`/`Tag`，用 GPUI 布局排列；激活/焦点只由一个实际 `Button` 所有，不嵌套两个可点击层。按实际内容区宽在三列和两列间切换。 |
| 详情 | `WindowExt::open_sheet_at(Placement::Right)`，`Sheet::size` / `title` / `footer` / `on_close`，关闭回到来源格子或活动行。`Settings` → `SettingPage` → `SettingGroup` → `SettingItem` / `SettingField` 保留有意义的设置区、原保存逻辑和路径选择。用途和调用详情用 `GroupBox` / `DescriptionList`；错误用 `Alert`。 |
| 确认 | 现有 Kit `Dialog`、`DialogFooter`、`DialogAction`、`DialogClose` 和 `DescriptionList`；实际焦点与关闭归 `Root`。正常/替换/失败/重复分支独立；重要风险和操作不折叠。 |
| 反馈 | 使用原 `Notification` 和会话活动所有者。目录空态、筛选无结果分别使用 `Empty`；处理进度可用原有 `Progress`，没有真实总量时不填百分比。 |

实现保留已有包身份、信任复查、事务、运行与取消、IPC 关联 ID、返回来源和应用层延后回调。不改 Rust/C# 所有权，不创建新 HWND，不新增协议、市场、联网检查或自动安装解释器。

## 验收

- 1060×650 浅色和 920×480 深色，以及最小尺寸的相反主题：搜索、筛选、进入详情、返回焦点；长文本不得让主要动作或风险不可见。
- 鼠标、Tab/Shift+Tab、Enter、Escape 和中文输入；打开详情后背景不抢焦点，返回保持目录上下文；真实小窗的剪贴板反馈不改位置。
- 新包→信任→启用逐步验证；无效 ZIP 可重新选择；相同内容零写入；替换前后可核对实际变化；失败→编辑→取消/保存分别观察原草稿和保存结果。
- 原型仅以示例数据模拟流程。HTML 的尺寸和浏览器交互不替代 GPUI 编译、Windows DPI/焦点、读屏器或用户确认。
