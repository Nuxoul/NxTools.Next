## Proof requirements
1. Compare owned files against checkpoint: no domain/schema/native command/controller/key policy changes justified solely by appearance.
2. Preserve existing functional test assertions. Update an intentional geometry expectation only with a measured new-boundary regression; don't delete containment/state assertions to obtain green.
3. Feature selectors/field declarations/callbacks and source-backed inventory help detect omissions; static presence alone cannot prove live functionality.
4. Focused owner suites then integrated desktop/lint/check/fmt and relevant lifecycle gates. No compilation while independent writers are active.
5. Actual synthetic GPUI rendering at default/minimum and fixed budgets; native pointer/DPI/user installation remains separate. No real user clipboard/history/config enumeration, URL/network/service/DOpus operation for fixtures.
6. Record exactly changed surfaces and deferred ones. '485 tests pass' does not mean every page visually accepted or every historical behavior natively exercised.

No new diagnostic payloads or secret-bearing logs. Rendering changes reuse existing lifecycle correlation. No automatic package/install/commit/push after this checkpoint unless separately requested.
