## Scope

The approved Acrylic theme covers the entire application; palette/font selection is independent. Formal settings and the pinned framework amendment are integrated; native material and whole-app surface adoption follow the canonical implementation plan. ## Window-frame invariant

The baseline GPUI Windows custom-titlebar boundary restored only the top client edge after DefWindowProc. Caption/window-edge styles could reserve side/bottom non-client pixels. Native Acrylic must not expose a second glass collar outside the GPUI surface. The formal shared client boundary below replaces that behavior while retaining resizing and native-caption ownership.

For the fixed proof, client size/screen origin are preserved, Caption and WindowEdge alone are removed, SysMenu/other bits are retained, and FrameChanged uses NoActivate/NoZOrder. The helper checks the visible/client alignment and rejects THICKFRAME rather than removing resize behavior. No fake DPI/settings notification, root crop, opaque cover or second overlay is used.

The framework's live logical size/origin follow actual WM_SIZE/WM_MOVE. Its saved `window_bounds` uses the restored border-offset cache. The fixed fixture does not persist bounds and does not certify production placement/resize; formal production cache and regression boundaries are recorded below.
