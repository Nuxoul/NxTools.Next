## Invariants

One original batch HWND/Root holds summary and selected member detail; association precedes member auto-open/dispatch. Each running member retains its own ticket, generation and connection. Explicit switching does not answer/cancel another ticket. Background/close/details are presentation only, and current pending decisions recover on a deferred turn. Keep FIFO/head overlap, two running, cleanup-held slots, local queued Stop and actual acquired-pause confirmation. Counts distinguish archive jobs, skipped files, refused admission and unknown cleanup/publication.

Batch reuse is unchecked by default in the original eligible Password Dialog. Native session owns one protected candidate per original batch; plaintext exists only while answering a matching prompt and temporary bytes are zeroed. Confirmed WrongPassword state/failure invalidates before another member can reuse; ambiguous authentication/data failure retains its exact category. Current operation/session/generation/batch and one-use ticket checks precede retention. Retry generations cannot install a candidate for the original batch. Explicit retirement also disables retention/reuse on that batch's still-active members, so a late reply cannot recreate the candidate. No settings/global cache, preview grant or OLE authority is created. Cancel, retry generation, disconnect, aggregate retirement and disposal clear secrets without releasing the original worker's cleanup-held ownership early.

`progress.rs::show_prompt` keeps a checked original Checkbox visible when current eligibility retires, using `Field::description` for the explicit-uncheck path. Its original `Dialog::on_ok` rejects before password construction/input clear/close/deferred reply; `jobs.rs::reply_job` retains the final admission guard. `batch_jobs.rs::job_observation_result` clears current `worker_state` at Retry generation transition, pumps the original queue, then publishes the deferred snapshot. `batch_snapshot_for` uses that current-attempt fact for Admitting/Running and preserves `ever_started` solely for historical never-started counts. Exact callback regressions are recorded in the [batch contract](../../.trellis/spec/nxtools-desktop/backend/archive-batches.md).

Standalone Test/full Extract uses the original initial ArchiveSpace v2 observation before native terminal, bound to receipt/attempt/session/generation/connection. First valid baseline is immutable. Explicit retry requires affirmative zero publication, actual cleanup, zero commits/skips, allowed code and fresh matching source/target observation; once pending, duplicate actions cannot dispatch another attempt. Create/Modify/selected/HZ5/post-Test/unknown/published/unclean shapes remain ineligible. Warning success with actual location/cleanup permits manual Locate; auto-open remains clean Succeeded only.
