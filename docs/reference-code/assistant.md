## Behavioral invariants to preserve when in scope
- Independent transparent/non-taskbar topmost surface does not activate or steal focus merely on show/hover/drag. Explicit Open Main/Add Download deliberately activates its destination.
- Dragging remembers final position and cannot also dispatch a click. Legacy click predicate uses total movement<6device pixels and press duration<450ms. Capture loss ends drag and saves position without click. The locked-pointer branch does not set `_isDragging`, so its ordinary release currently returns without click: preserve intent, do not copy this bug.
- Position clamps against monitor work area after display changes; source logical size becomes correct DPI-scaled native bounds. Edge-hidden presentation retains8device pixels, reveals on hover, and pauses GIF rendering.
- Base/hover transparency has separate values; restoring from fullscreen/edge hiding preserves selected appearance. Fullscreen legacy uses opacity0/hit-test-off, which is not proof of native mouse click-through.
- Static input has no animation timer. GIF decode and timers retire on replacement/close; delayed completion must not overwrite a newer asset.
- Download UI reflects existing task state; actions use the normal download confirmation workflow, not a parallel engine.
