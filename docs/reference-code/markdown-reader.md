### Native open selection reference

The shared ordinary-command chain is [`CommandRouter::enqueue`](../../rust/crates/nxtools-ipc/src/lib.rs) (pending command without the machine deadline) → [`PlatformPipeClient.ReadLoopAsync`](../../csharp/NxTools.PlatformHost/Protocol/PlatformPipeClient.cs) (`ValidatePickerPeer` against `GetNamedPipeServerProcessId`) → [`PlatformCommandSequenceDispatcher`](../../csharp/NxTools.PlatformHost/Protocol/PlatformCommandSequenceDispatcher.cs) → [`BoundedStaOperationRunner.TryRun`](../../csharp/NxTools.PlatformHost/Windows/BoundedStaOperationRunner.cs) → [`StaDialogRunner.RunInline`](../../csharp/NxTools.PlatformHost/Windows/StaDialogRunner.cs) → [`PickerOwner.Run`](../../csharp/NxTools.PlatformHost/Windows/PickerOwner.cs) → WinForms `OpenFileDialog.ShowDialog(original owner)`. The file-dialog configuration and modal-return pattern are observable in the [extension manifest picker](../../csharp/NxTools.PlatformHost/Windows/ExtensionManifestPicker.cs); the [archive source-file picker](../../csharp/NxTools.PlatformHost/Windows/ArchiveJobPicker.cs) demonstrates `Multiselect` and complete-vector return. Neither feature owns the Markdown chooser.

Preserve native placement/focus (no explicit activation), the exact HWND/peer before and after modal return, and the owner-loss timer/session close path. The one STA reservation lasts through actual modal exit and cleanup; human selection has no elapsed deadline. Native user Cancel returns an empty selection; owner/session retirement and native failures never publish selected paths. Filter `.md` / `.markdown`, and validate and bound the whole result before publishing rather than returning a prefix.

`pick_markdown_document` returns the existing `platform_command_result` correlated to the request ID. The successful `data` string encodes `{"paths":[...]}` (empty array on user Cancel). Accept at most 32 paths and 128 KiB of aggregate UTF-8 path bytes, leaving space for JSON escaping within the existing 1 MiB frame.

### Native export path

The reader freezes the current source (including a draft) before `pick_markdown_export`. The same authenticated owner and detached modal lane return a plain path or successful empty data on Cancel. Rust writes offline GFM HTML in a sibling staging directory. C# [MarkdownPdfPrinter](../../csharp/NxTools.PlatformHost/Windows/MarkdownPdfPrinter.cs) uses one dedicated STA and WebView2 with no script or network navigation, then returns a separate correlated `print_markdown_pdf` result for the staged PDF. Rust checks the result and publishes on the same filesystem. The selected target is never passed to the renderer. Missing runtime does not affect HTML, reading, editing or history.

### Reader-owned history

SQLite stores exact committed UTF-8 bytes and metadata by canonical document path; consecutive equal bytes are not captured again. `markdown-versions.sqlite3` lives in the existing app-data directory. Keep the latest 32 unnamed versions per document and retain named versions. Restore commits a recoverable before-state before the guarded file replacement. An ordinary save or successful restore reports history recording failure separately from the completed file operation.

### Winc mode, outline and code-color behavior

- `crates/winc-app/src/app/preview/images.rs::choose_preview_mode` and `set_preview_mode` select Source, Split or Preview; `app/snapshot/preview/markdown.rs::markdown_files_get_the_three_way_switch` checks the left/right split, source-only view and editable preview-only view. The same document and source revision survive the transition, and leaving preview aligns the source to the location currently at the top. Winc also records its chosen default for later tabs.
- `view/preview/markdown.rs::draw_toc` renders the left rail for at least two nonempty headings. The active entry is the last heading at/above the viewport top, the last visible heading at the end, or a just-selected target until the next independent scroll. Delayed hover opens the hierarchy; pinning yields back to the rail if it would crowd the document. `app/preview/markdown/scroll.rs::press_toc` owns pin and jump; `scroll_markdown_to` and `sync_markdown_scroll` map both directions through `laid.rs` source/geometry, not pixel ratios. Verify using the committed viewport and preserve keyboard access rather than relying only on hover.
- `app.rs::set_hover` treats outline marks, card rows/padding and the scrollbar as one region; crossing them does not restart `theme.rs::TOC_HOVER_DELAY` (200 ms). `draw_toc` computes the card origin from the active mark and freezes it while open. It grows the card's clip from the intersection of the marks' hitbox and the final card, then reverses that transition on leave (`app/animation.rs::TOC_FADE`, 160 ms). The closing card is not interactive. `app/preview/markdown/scroll.rs::press_toc` only handles Pin/Heading: a click on `Bars` does nothing. Heading jumps keep the card open and tint the measured target (`TOC_FLASH`, 1200 ms); Winc also glides to the target and interpolates the pin position. When there is not enough room, the pinned list falls back to the rail. The existing reader owns Tree, named XSmall ghost pin Button, source anchors, and a keyboard path; no vendor changes.
- Winc `app/input/mouse/target.rs` resolves the outline hit before `MarkdownText`; `click.rs` dispatches those targets separately. Locked Base0.8.0 `text_selection.rs` installs a window selection layer: its bubbling left down begins the gesture, bubbling mouse move projects an active gesture even without a pressed button, and bubbling mouse up ends it. The reader's floating/pinned outline owns its left-down boundary; heading click must not suppress the release needed by the official Tree and Root. Test this through the same Base Root as `show_window`, including a normal text drag before and after outline navigation.
- Winc fenced code colors are produced by `winc-typeset/src/code.rs::code` through `winc-syntax::find` and per-line lexer state. NxTools' source editor sets `Language::Markdown`. The reader's Base TextView consumes the highlighter installed by Kit `component::text::install_text_view_defaults`; a recognized fence reaches the registered grammar via `component_code_block_highlighter`. A language caption or successful code copy does not prove the renderer painted different token colors. - Locked Kit 0.8.0 `text::editor_host::parse_markdown` uses the TextView parser; top-level source spans pair with the matching committed `rendered_text()` revision and `list_state()`. ### Winc Source and Split layout

- `crates/winc-app/src/app/lifecycle/window.rs::relayout` → `place_split` allocates 50% to the source by default; the stored `preview.split_share` is proportional, with 240 DIP minimum per pane. If the total is under 480 DIP, the right pane is not placed. ## NxTools interaction and failure invariants

One activatable, resizable reader window; reopening the tool focuses it. Tab deduplication, per-tab scroll, real user-driven mode switching, captured document revision and one scroll owner per pane. Chooser cancellation is a no-op; retirement cannot install late data into a replacement window. Keep native caption targets and editing controls distinct. A clean tab follows an external save, a dirty tab retains the draft and indicates conflict, and failure never drops the last-good view. Export does not save the source; restore retains the before-state before replacement. Verify actual button click/focus, chooser/native behavior, logical document state and successful output separately.
