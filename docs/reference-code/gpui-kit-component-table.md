## Corrections this table must prevent

- Match the requested visible structure: Extensions catalog cells/tiles follow Other Tools, not an invented text-heavy list. ListItem is presentational and can form tiles; GPUI grid/wrap arranges them. Neither official Card nor Grid is declared in the inspected locked catalog. Do not fabricate imports or choose DataTable merely because the user said cells.
- Import/environment/download-chain/recent-activity commands need visible outlined official Buttons. Toolbar.child calls prepare_for_toolbar -> Button.ghost().compact(), then size. Medium fixes height, NOT this appearance. Use the released public content composition for outlined actions and test actual keyboard/paint integration.
- Official theme/font/control grammar stays; custom divs may arrange layout but must not replace available styled controls. Existing feature state/native ownership is retained.
- Source imports, passing tests and screenshots inspected by AI do not override explicit user rejection. Current Extensions visual remains rejected pending a separate implementation correction.
