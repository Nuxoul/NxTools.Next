Authority: approved `.pi/plan/统一-markdown-组件与六项体验改进-20261022-1342.md`, section6. This intentionally supersedes earlier built-in-only palette policy for Default Light/Dark/System, not optional official themes, fonts, geometry or native behavior.

Exact released API chain: `vendor/gpui-component-0100/src/theme/registry.rs::load_themes_from_str` registers new names but does not replace `default_themes`, even with `is_default`. Therefore original project assets `nxtools-graphite-light.json` and `nxtools-graphite-dark.json` register distinct names, and `theme.rs::apply_active_theme` explicitly selects them for default modes. Public `Theme::update` assigns light/dark configs, then `Theme::change` applies config and synchronizes renderable tokens/Base. Existing optional Catppuccin/Gruvbox/Solarized configurations remain unmodified and selectable. Fonts retain installed YaHei UI/Consolas; no radius/type/control-size override.

Source-icon gradients remain original RGB metadata, not indigo.
