AI 如何优先选用

先匹配用户参考形态，再查复合组件，然后组合官方控件；保留原业务状态、窗口、焦点与原生边界。普通布局 div 可以用，不得手绘替代已有按钮、输入框、开关、弹窗。

单元格：Kit ListItem + Icon / Label / Tag + 真正的 Button，grid / wrap 仅负责排列。没有独立 Card / Grid 不等于做不了单元格，也不能编造类型。表格数据才选 Table / DataTable。

明确操作：官方 Button.outline，默认 Medium32；有主次时选择 primary。保留轮廓的操作可通过 Toolbar.content 公共组合，必须验证最终绘制和键盘行为。不要用测试数量替代视觉验收。
