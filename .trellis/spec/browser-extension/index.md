## Module layout (2026-10-22)
- Background: `background.js` is a thin entry (listeners only). Dependencies are classic scripts sharing the worker global scope: the four `*-policy.js` modules plus `bg/*.js`. One ordered list must be identical in the entry `BACKGROUND_DEPENDENCIES` (Chrome `importScripts`, guarded by `typeof importScripts === "function"`) and manifest `background.scripts` (Firefox event page, dependencies first, entry last). Manifest also declares `minimum_chrome_version: "121"` because older Chromium rejects MV3 `background.scripts`.
- Content: `content/*.js` are idempotent isolated-world namespace modules on `globalThis.NxToolsContent` (frozen exports, re-injection is a no-op, no shared page state); `content-script.js` remains the single owner of overlay/drop/capture/direct-download state and the `__nxToolsMediaBridgeInstalled` guard. Manifest `content_scripts[0].js` must equal background `CONTENT_SCRIPT_FILES` (re-injection). Never split content code into shared top-level `const`/`let` scripts: the bridge is injected twice into the same world.
- Popup: `popup/format.js`, `popup/dom.js`, `popup/render.js`, `popup/actions.js`, entry `popup.js`, loaded in `popup.html` order. Rendering uses DOM APIs only (no `innerHTML`).
