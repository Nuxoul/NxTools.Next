Measured layout contract (refine-browser): header above tabs ≤120px (brand + connection one 40px line, page title + domain one line); capture page shows ≥4 resources in the default viewport; resource rows are `[check][type icon][name / kind·resolution·size][preview][download]` with actions on the title line; badge/track hint/MIME/source/full address live in the expanded preview and tooltip; type markers are inline SVG built with DOM APIs; batch bar is hidden until a selection exists (1..32, sticky); the disabled merge placeholder is not offered (background `popup_merge_resources` stays); task progress and actions share one line with semantic status tone; settings rows ≤50px; the status bar is hidden while idle, success fades after 4s, errors persist with a dismiss button; the "popup never starts the desktop" note lives in Settings › 本地连接.

Tabs retain selected/hidden/roving TabIndex and Arrow/Home/End; filters/features expose pressed state. Native buttons own Enter/Space; resource preview is a real named button, Escape closes and returns focus. Repaint restores eligible resource/task button focus and preserves focused speed draft. Batch 32/accepted-only deselection/media frame-index messages remain. Pending controls suppress duplicate actions (`aria-busy`) and catch failures in visible live feedback; errors preserve draft/retry. Task progress uses native progress value/max, never inline style blocked by extension CSP. Popup rendering never parses HTML strings.

Popup and both Shadow roots respect reduced motion; no decorative idle ticker/animation. Injected media entry 28px and original candidate/Escape/placement owners retained; chooser rows use the same type icon + two-level text (name 13/20, metadata 12/18); status visually readable in fixed viewport-safe feedback. Drop target 96x48 minimum hides redundant icon/subtitle, retaining primary action. Shadow stylesheet remains adopted/page-isolated.

Verification: all Node suites plus `node browser_extension/nxtools-interceptor/tests/refine-browser.cjs`, `layout-browser.cjs`, `redesign-browser.cjs`, `content-browser.cjs`. Separate temporary Chrome profile, mocked Chrome API, all network blocked. Real DOM actions/keyboard/geometry/partial retry/no-unhandled/Save/busy/reduced-motion checks and an inspected state gallery are stronger than source strings, not installed extension/real page/physical/high-DPI/reader acceptance. Gallery/preview generated by `tests/build-preview.cjs` (loads popup scripts in `popup.html` order) with strict local CSP; fixture never ships in production popup or manifest.

## Workflow polish
Keep the456px graphite four-tab layout. Home and Settings share one session-pause operation/busy state; Home exposes fixed connection failure guidance and explicit retry. Remember only the selected view in `storage.local.nxtools_popup_view`; late restoration cannot override a user choice or fresh link review. New review switches to Capture once per ID. Tab changes refresh the requested view after any earlier request settles.

Name/domain search is local and preserves hidden selections. Other-page resources use collapsed native details. Resource lists start at24rows and expose further groups of24, allowing all120review candidates to be reached. Extraction is explicit and review-only. Resource details offer demand-only inspection with busy/failure/retry and normalized flags. Pending/protected resources cannot be submitted; protected state removes selection. Escape retains original details-button focus. `tests/polish-browser.mjs` consumes a supplied ego-browser Page to exercise production DOM, delayed refresh,120-link reachability, keyboard/focus, geometry, reduced motion and content selection/XML parsing.
