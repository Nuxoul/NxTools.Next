## 3. Contracts
Edit-only fixed512-byte catalog is deliberately stricter than ordinary read/test/extract. Preserve raw ordinary ustar/GNU headers, local PAX allowed fields and GNU long-name records; modify only necessary path/size/checksum/extension representation. Allowed local PAX keys are path,size,mtime,atime,ctime,uid,gid,uname,gname. Preserve exact supported time values/precision and uid/gid/mode/identity strings; not full POSIX/NTFS/ACL/ADS fidelity. Unknown semantic/global extensions, links/devices/sparse/special types and ambiguous duplicate/case/file-prefix/implicit-parent spellings refuse before candidate write. Require checked headers/extents, two zero end blocks and zero tail. TAR has **no payload checksum**: transaction SHA256 compares bytes, not intrinsic TAR integrity.

TAR-AC01 raw-byte dependency rule: a member change does not itself authorize canonicalization. Recompute the main checksum only when main header bytes actually change; a PAX/GNU-only pathname override must retain the complete original main header. Replace only affected PAX path/size records and retain all other records, including valid original record-length/numeric representations. An extension payload change alone does not change its header checksum: retain the whole header when payload length is unchanged; update size and its dependent checksum only when length changes. New headers start with valid checksums. Required size changes must still update dependent fields; never retain stale size/checksum merely to preserve bytes.

Add uses original protected source IDs/CreationPlan, including directories/zero-length files/empty directories; zero-length files still open/read EOF/close. New records use uid/gid/mtime0, file0644/directory0755, no ACL/ADS conversion. Replace/overwrite keeps old metadata/name. Delete expands component-ended subtree prefixes and overlaps; delete-all creates a verified legal empty TAR, never deletes source. Rename preserves a/ versus ab/, rejects self-descendant or occupied explicit/implicit target directories. Replacements/new entries follow retained old entries deterministically; byte layout/order is not claimed identical. Original private conflict tickets/apply-all/skip/auto-rename remain; all-skipped is warning/zero publication.

Outer compression is separate: actual signature plus complete decode and TAR inspection, never suffix authority. Gzip exactly one member; preserve mtime/OS/name/comment, XFL0/2/4 maps level6/9/1; refuse FTEXT/FHCRC/FEXTRA/unknown XFL. Existing complete gzip reader still verifies all trailers/members before edit refusal. XZ exactly one stream and LZMA2-only filter; preserve check0/1/4/10, reencode preset1; disclose changed parameters/block layout. Normal multi-stream reading policy remains unchanged. Finite anonymous decoded TAR, inner candidate, outer candidate and held-readback spools; no extraction tree/whole-archive Vec. Every spool/decoded payload/count/extension/metadata/working-memory/control/native Job time budget is finite. Each extension <=64KiB, at most2 pending distinct extensions; parent indexes charge before allocation. Original+candidate/spools coexist, no source deletion credit, estimates may be unknown.

Complete TAR end/checked flush -> checked outer finish/flush -> local full exact member/header/extensions/content comparison -> native held partial full encoded hash/readback -> complete outer decode and same exact TAR/content comparison -> close old readers -> original `edit_reads_complete` -> C# held-source fullID/version/hash/target/candidate checks -> final cancellation -> release **only original FILE** -> one original native publication. Parents/candidate remain protected. Accepted final-check/close/path-publication TOCTOU is not ID-CAS. No delete-old-first/backup/truncate/global sharing relaxation/recursive cleanup/retry on unknown.

Use existing queue/serialization/pause/cancel/lease policy and deferred cross-entity callbacks. Fixed real phases planning/reading/reencoding/verifying/committing cross existing progress route; processed is not committed, unknown totals stay unknown. Original correlation accepted/start/phase/terminal/elapsed/native errors, bounded/coalesced diagnostics; no names/paths/content/password/chunk events. UI uses existing Form/Field, official Small nonclosable warning Alert, original outlined actions/Root/titlebar; disclose full rewrite, compression changes, space, new metadata and checksum limitation. Step4 interaction unification is not part of this slice.

## 4. Validation & Error Matrix
Stale ordinal/prefix/native/revision/protected source/EOF mismatch -> SourceChanged. Unsafe path -> UnsafePath; case/duplicates/prefix collisions -> OutputCollision. Lossy structure -> UnsupportedOperation; unsupported codec/check -> UnsupportedMethod. Header/trailer/tail/extent/readback/content mismatch -> CorruptArchive. Encoded/decoded/spool/working/metadata/count limits -> ResourceLimit. I/O/finish/flush failures propagate before publication. Native5 -> FailedBeforeCommit; native64 -> CommitOutcomeUnknown, retained evidence/no automatic retry; late cancel preserves published journal. Ordinary read leases/preview/drag/nested owners are not weakened.

## 5. Good/Base/Bad Cases
Good: independent Python PAX precision/uid/gid/mode seed edited once and independently decoded; old source readers exclusively reopen at handoff; delete-all independently opens as empty. Base: ordinary plain TAR ustar files/empty directories. Bad: metadata dropped by generic reader then reconstructed, suffix grants editing, gzip ISIZE used as total, XZ filter silently removed, finish-only candidate committed, transactional hash called TAR checksum, or skipped edit reported as publication.

## 7. Wrong vs Correct
Wrong: feed TAR into ZIP/7z editor, fully extract survivors to paths, silently normalize unknown PAX, release source early or claim whole PhaseE complete. Correct: separate strict TAR catalog + bounded outer codec -> exact complete candidate -> original native FILE-only handoff/single publish. Compilation/fixture/AI-inspected render bounds are not physical Explorer/IME/DPI/user/installed acceptance. Stop after Step3 for independent coordinator acceptance.
