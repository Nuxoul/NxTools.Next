## Native adaptation
Keep original source-owned C# passive popup styles/monitor/DPI/finalclient readback and unique prepare/frame/reveal/adjust/hide phases. Hidden first correctly sized scene explicitly drawn after host lease. Visible content/hover/focus changes resize in place, never hide/reveal. Host measures content height and current-generation content-focus scope through public prepaint, plus pointer-in-stack geometry, only to allocate enough native client for official expansion; it does NOT calculate/paint card offsets or drive official hover/expiry/focus. Debounce native collapsed shrink until official reflow settles; no per-frame diagnostics or fullscreen transparent catcher. Reconcile removal/replacement/empty/reposition state so new notices do not inherit expanded transparent area. Position-only changes update official global placement without recreating notification entities or restarting remaining lifetime. Final empty waits official on_close/exit before hiding. Native readback/source retirement/stalephase checks unchanged. Native animation snapshots and disconnect/unknown policy also reach GPUI reduce-motion.
