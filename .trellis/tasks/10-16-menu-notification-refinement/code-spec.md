## 3. Contracts
Core original locked global transaction persists local draft before next-turn position publication. Each action checks same live generation/nonexiting/unclaimed before returning a callback; callback executes after center lease on the source window. Finish takes session once, closes popup on next turn, then restores original focus/dispatches original callback only for current trigger/source session and no newer menu. Outside click closes source appropriately; Escape preserves source. Watchdog/disconnect retires exact session, no source-window clipped fallback in production. ## 4. Validation & Error Matrix
- Missing position in old config -> BottomRight; valid six enum values round-trip; unknown enum fails normal serde validation.
- Global draft Cancel/persistence failure -> no position change. Successful save -> position updates next app turn; no Windows registration needed for location-only save.
- Old notification generation/invalid action index/already claimed/exiting -> no callback. Same-ID replacement has new generation; old timer or dismissal cannot remove it.
- Closed/replaced Clipboard origin or retired run/result -> no navigation/reopen/retry. Script-only item_id -> result count0/no ViewResult. Cancel does not imply rollback of arbitrary trusted effects.
- Invalid/foreign/visible popup/native readback failure -> reject, keep source available; native error code at C# owner. Duplicate/late phase result -> ignore. Source closed/trigger stale/new menu -> discard callbacks.
- Disabled ancestor -> no executable leaf. Escape -> retire menu only; outside -> original source hide; popup first nonactive/prepaint state is not dismissal.
- Narrow notifications -> bounded width/text scroll/actions contained; no full-window blocker, polling or animation logs.
