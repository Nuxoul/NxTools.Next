Other features use compact24 roles plus default32 form roles; user now explicitly requests consistent extension text actions, adopting official default32 without global restyling. Read full docs/reference-code/gpui-kit-component-index.md and released Form/Field, Dialog parts, DescriptionList/GroupBox/Accordion, Button sizing. Preserve KitDefaultLight/Dark, existing CJK/mono/1060x650/min920x480/176rail.

Fix this caller seam, not add engine. Read original ExtensionRuntimeInspector/ExtensionProcessRunner; WinShun Programs.cpp reference indexed by docs/reference-code/winshun.md. Automatic discovery only on explicit opening environment/trust, never animation/render loop. No native/user program reference executed.

## Composition
Extension text buttons use default Medium; snapshot actual comparison. Trust opens released Kit Dialog using original Root/focus/Enter/Escape/Action/Close and same semantic layout as import. Noneditable runtime summary/version and source concise; source/codehash/entry/budgets in collapsed details; permissions readable, warning fixed above footer. Runtime missing -> explicit notfound and browse option, no dead readonly Input. One original trust decision and separate enable.

## Discovery and lifecycle
Environment inputs initially unconfigured -> deferred empty-path Inspect command; original request UUID/inputvalue/target checks before applying result. Valid discovery schema includes supported program/absolute executable/hash64/version<=128. Update draft only; Save explicit. Detection must not overwrite a typed path. PATH absent -> local retry/manual choice. Trust draft captures id/contenthash/selected runtime, discovers only absent selection; request ID and target scope; delayed result cannot update another trust decision. Current selected runtime changes during draft invalidates admission; actual app approval checks expected package hash/path and rehashes in original atomic Core approval. Legacy configured path remains honored. EXE staged identity no PATH.

Low-noise original correlated runtime diagnostic events retained, no path/version/output telemetry. Native malformed PATH segments skipped,256segment cap, fixedfilename only/no cwd/WindowsApps. Existing probe Job3s256MiB2processes4KiB cleanup gate.
