# 自动检测运行环境与信任确认

- 已安装 Python、Node.js、Windows PowerShell 或 pwsh 并加入 PATH 时，打开“扩展 → 运行环境”会自动检测未配置的项目，无需复制完整路径。检测结果显示在草稿里，保存后才成为默认设置。
- 对尚未配置环境的单个扩展，直接点“查看并确认信任”也会自动检测其所需解释器。显示版本与来源后可直接确认信任，无需先跳转设置页。检测不会运行插件，也不会自动信任或启用。
- 检测不到时，确认信任按钮禁用；可在固定底部区“重新检测”或“选择其他解释器”。已有虚拟环境可选择 `Scripts\python.exe`。
- 已有默认路径或单扩展覆盖优先使用，不会因配置失效偷偷换成 PATH 中另一份解释器；需要更换时进入运行环境编辑。手动选择的候选检测失败后重试仍检查同一路径。
- 信任框只默认展示名称、版本、用途、解释器版本和选择来源。完整路径、内容哈希及运行上限位于技术详情；风险说明固定可见。信任后还需单独启用。
- 取消不保存；确认信任时会重新校验代码和解释器哈希。检测后路径、代码或配置变化会拒绝旧确认。

信任后，此插件可使用当前用户的全部权限。以下权限由插件作者声明，并非系统访问限制。
