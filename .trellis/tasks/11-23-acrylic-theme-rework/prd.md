# 磨砂主题按生态做法重做（原生预览先行）

## Goal

按 11-22 调研结论（`../11-22-gpui-theme-acrylic-research/research/README.md`）重做磨砂主题：
DWM 系统材质、独立的中性材质调色板与单层分层、系统圆角加自绘 UnderBorder、实底恢复
ClearType、首帧遮蔽。先用独立原生预览让用户验收，验收通过后再改产品。

## Requirements

### R1 材质（DWM 系统背景）

- 全局「主题风格」：实底 / Mica / Mica Alt / 亚克力；常驻窗口（主窗口、设置、下载）使用所选系统背景
  （38=2/4/3）。Windows 10 只提供实底 / 磨砂。
- 瞬态界面（速启、剪切板、链接浮层、文件对话框搜索）：亚克力（38=3 `DWMSBT_TRANSIENTWINDOW`）。
- 系统版本低于 22621：回退 WCA Accent3（模糊）；Accent 也不可用时回退实底。
- GPUI 窗口背景在材质模式下为 `Transparent`，DWM 属性在 Transparent 之后写入。

### R2 调色板

- 磨砂模式使用独立的 Fluent 式中性材质调色板：中性底色 + 带 alpha 的墨色文字与描边。
- 配色方案只驱动强调色与选中色；实底风格保持现状不变。

### R3 分层

- 标题栏、侧栏、工具栏 alpha 0，直接露出系统材质。
- 内容区只有一层：浅色约 0.50、深色约 0.45（相对浅色 ×0.9）。
- 卡片使用低 alpha 填充；菜单、对话框、输入框不透明。
- 设置里的滑块只调内容层，范围 50%–100%。

### R4 圆角

- Windows 11：DWM `DWMWA_WINDOW_CORNER_PREFERENCE`(33)=ROUND，`DWMWA_BORDER_COLOR`(34)=`0xFFFFFFFE`（无系统描边）。
- GPUI 自绘 8 DIP 圆角与 1px UnderBorder 描边：背景与描边是同一个元素。
- 去掉 GDI HRGN；Windows 10 所有窗口保持方角。（已被 2026-11-26 用户验收的方案 ④ 取代：Win10 区域圆角 + 独立阴影窗口，见 implement.md。）
- 需确认 DWM 圆角半径在 100%/125%/150% 缩放下与 8 DIP 吻合。

### R5 ClearType

- 实底风格窗口以 `Opaque` 背景渲染（GPUI 仅对 Opaque 窗口启用子像素抗锯齿）；
  只有磨砂模式切换为 `Transparent`。

### R6 首帧

- 窗口用 `DWMWA_CLOAK`(13) 遮蔽，材质属性写入且首帧呈现后再解除遮蔽，取代 90ms 实底保持。

## Acceptance Criteria

### 预览（本任务第一阶段）

- [ ] 预览可在 实底 / Mica / MicaAlt / 亚克力 / Accent4 回退 间切换，浅色与深色均可切换。
- [ ] 常驻工作台窗口可调整大小；标题栏与侧栏直接露出材质，内容区为单层，卡片、输入框、菜单层次清晰。
- [ ] 剪切板与搜索两个瞬态浮层使用亚克力。
- [ ] 圆角处无白边、黑边、方角残留；描边连续，100%/125%/150% 缩放下与 DWM 圆角吻合。
- [ ] 实底模式文字为 ClearType 子像素渲染。
- [ ] 打开窗口时看不到透明空框、实底闪烁或材质迟到；日志记录解除遮蔽的路径（首帧或超时兜底）与耗时。
- [ ] 浅色与深色壁纸上正文清晰可读。
- [ ] 用户确认视觉效果。

### 产品（第二阶段，用户验收预览后开始）

- [x] C# 材质所有者按界面类别选择背景类型，带 22621 门槛与回退。
- [x] Rust 主题实现中性调色板与单层分层，实底风格不变。
- [x] 实底风格窗口以 Opaque 创建。
- [x] 遮蔽式首帧取代 HRGN 与 90ms 保持；相关测试与文档同步更新。
- [ ] 用户实机验收（Win11 100%/125%/150%、Win10 拖动与方角）。
