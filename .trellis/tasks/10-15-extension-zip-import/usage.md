# ZIP 扩展导入

## 使用流程
1. 左侧工作区“扩展” → “导入扩展” → “选择 ZIP”。也可输入 ZIP 的完整路径后点击“检查扩展包”。
2. 软件校验 ZIP，显示官方 Kit 确认对话框。先检查名称、版本、用途、功能、作者声明的权限；完整来源路径、SHA-256 和运行限制位于“技术详情”。
3. 点击“导入扩展”；同 ID 已存在时明确显示“替换扩展”。取消、Escape 或关闭不安装。保存失败保留对话框，可以重试或取消。
4. 软件将清单及声明文件写入配置目录旁的 `extensions/<扩展ID>/<内容哈希>/`，安装后可以删除源 ZIP。导入或替换后保持停用、未信任。
5. 脚本扩展在“运行环境”配置解释器，再在“信任与启用”单独确认信任、单独启用。保存路径、版本检测或导入本身都不等于授权。

信任后，此插件可使用当前用户的全部权限。以下权限由插件作者声明，并非系统访问限制。

## ZIP 结构
支持以下任一种，不支持一次打包多个扩展：

```text
clipboard-cleaner.zip
├─ extension.json
└─ main.py
```

或 ZIP 内唯一一层文件夹：

```text
clipboard-cleaner.zip
└─ clipboard-cleaner/
   ├─ extension.json
   └─ main.py
```

所有运行依赖/资源必须列入清单的顶层 `files`，例如 `"files":["main.py"]`；`files` 不在 `runtime` 内。只保存声明文件与规范化清单，未声明的 README 等额外文件会校验但不安装。普通 UI 不再接受 JSON 或文件夹；原有已安装包与底层开发接口保持兼容。

## 兼容与限制
- 普通单磁盘 ZIP，Stored/Deflate；不支持加密、ZIP64、多分卷、自解压前缀、RAR/7z、替代 Unicode-path 扩展字段。
- ZIP 最大256MiB，清单1MiB，其余解压内容合计256MiB（包含额外文件），最多4096文件含清单、4096目录节点含隐式父目录；路径1024UTF-8字节、64层。
- 非 ASCII 文件名需标准 UTF-8 标记。拒绝越界/绝对/设备/ADS/保留名称、大小写冲突、重复条目、链接、特殊文件、损坏和大小伪造。
- 预览不创建正式目录。安装失败不会覆盖现有配置；若新内容快照已经发布但配置提交失败，可能保留未引用的已校验快照，避免误删共享文件。

本次源码及隔离验证不是安装版验收；现有 sequence6 安装包尚不包含本次改动。未重新打包、安装或修改服务。
