## Canonical stages
1. **Results and recovery**: preserve protocol completion separately from infrastructure failure; safe bounded text is intentionally displayed, never logged; handled is successful for manual actions. Confirm destructive removal through Kit0.8.0 Dialog/AlertDialog with explicit primary destructive action and outline Cancel; compare reviewed package/config under Core lock before commit, no repeat/late confirmation. Event last outcome/history is finite fixed-category metadata with correlation/time, terminal notifications dedup, recovery waits for next event.
2. **API contracts**: preserve legacy array responses and ZIPs. New qualified methods downloads.list_page / clipboard.query_page return bounded items/continuation/completeness; finite lifetime/current-run identity and memory budget, invalid cursor typed error, no unbounded snapshot. quick_launch.search stays catalog-only; new scoped response explicitly excludes index/async providers. Common method catalog advertises versions/input/result/error/limits and contextual restrictions. Optional required-method declarations default empty, reject unsupported early. Publish local JSON Schema and small disconnected helper/harness without new dependencies.
3. **Configuration convenience**: optional accepted input declaration defaults unrestricted for legacy; validate at menu and final invocation, explicit kinds/count/bytes, never trust declaration instead of runtime checks. Usage settings opens actual settings page. File/folder native dialog uses source HWND and pending-before-send, exact request/draft/package/input generation; cancel/stale/retired results never overwrite edits or save automatically. Existing resolver hosts selectable, original chain route/save owner retained.

## Lifecycle and diagnostics
Original owned immutable package/current trust/runtime identity, pending before observable dispatch, deferred cross-entity callbacks including cache-hit, request/generation/HWND checks, fail-closed publish and native cleanup accounting remain. No new show/hide/activation owner; file picker uses existing bounded STA and logical cancellation never claims to interrupt Win32. Low-noise extension.management/run/event/host_call stages reuse correlation IDs; new path picker logs accepted/start/terminal elapsed/native code only, no paths/text/URL/credentials/stdout/stderr. Cursor tokens never logged.
