## Evidence and diagnostics

Each actual test selection has a nonzero LIST and identical RUN, exact command, exits and selected/run/pass/fail/skip/not_run. A build prerequisite is not behavioral RED; a first-pass supplementary test is not fabricated RED. Actual native unregister/drain/COM/handle/thread/process retirement is distinct from fake counts, logical cancellation and ACK.

Measurements use already built binaries, serial equivalent workloads and AB/BA/AB pairs. No compiler or competing benchmark runs in timed windows. Keep raw rows, median, slowest and resource/request costs; check complete output bytes outside timing. Controlled delay results make no general Internet-speed claim.

Production diagnostics contain correlation ID, fixed state/reason, counts, elapsed time and native codes only. No paths/URLs/focus text/headers/cookies/credentials or per-event/per-byte logging. Temporary probes have unique DEBUG markers and are removed after the actual interaction is green.
