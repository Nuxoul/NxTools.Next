# Extension platform capability expansion

## Goal and user value
Enable extension authors to build image processing, local/cloud API workflows, stateful tools and responsive search without independently rebuilding host services. Deliver all seven requested capabilities through the existing extension platform: richer settings, progress, namespaced storage, host HTTP, image/blob exchange, full-source search and resident W10. This is a bounded first version, not an unrestricted plugin OS API.

## Approved product behavior
- **HTTP:** only manifest-declared exact scheme/host/effectiveport; public,localhost and private IP/hosts allowed. Trust shows targets; no wildcard/subnet blanket grant. No claim this constrains a trusted script's own network stack.
- **Storage:** explicit package upgrade carries its data; uninstall retains by default with explicit “同时清除扩展数据”; sameID reimport cannot automatically read orphaned data. Restore is explicit/reviewed; no silent merge or secureerase promise. Existing credential store untouched.
- **Compatibility:** old packages remain once/protocol1 unless author explicitly opts into new transport/mode. No autoenable/autoapproval/provider/event opt-in. Current packages require new trust when declarations/code/runtime changes.
