## Default request headers and reset

The exact ordinary-download default is:

```text
User-Agent: Mozilla/5.0 (Windows NT 6.1; Trident/7.0; rv:11.0) like Gecko
```

- One default definition governs new configuration, actual editable Settings text and real ordinary HTTP probe/transfer policy.
- Missing fields and legacy whitespace mean program default. Preserve existing nonempty custom headers; opening settings never writes configuration.
- Temporary blank editing is allowed. Apply/reopen restores consistent default semantics and visible text, not a hidden fallback behind an empty field.
- An official adjacent Button named 重置 restores only this field in the original TextareaState. Preserve entity/focus and every other draft field.
- Apply/Cancel remain the only persistence/abandonment route. Existing locked changed-leaf transaction preserves unrelated/concurrent fields. Failure retains draft and honest error; no applied-state publication before success.

- Exactly one ascending inclusive integer range, step1, retaining zero padding; example `file_{001..020}.zip`.

- Enforce the existing batch admission limit before any task creation. Reject oversize expansion and ask for a smaller range; never split silently.
- Submit only selected confirmed entries through the original batch command. Existing destination/name conflicts, duplicates and per-item outcomes remain authoritative. Partial acceptance stays visible; no whole-batch retry.
