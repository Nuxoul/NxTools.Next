# W6–W9 使用说明（源代码版本）

## 导入与启用
1. 在左侧“工作区”点击剪贴板下方的“扩展”，选择“导入扩展”，输入本地 JSON、`extension.json` 或插件文件夹路径，先预览再确认导入。首页列表支持按名称、功能和关键词搜索；“管理”进入独立详情分类。
2. 新导入与替换默认停用。声明式 JSON 检查动作后独立启用；脚本先检查来源、版本、代码身份、声明权限及用途，选择已安装运行时并明确批准信任，再独立点击“启用插件”。信任不会自动启用。
3. 警告含义：**信任后，此插件可使用当前用户的全部权限。以下权限由插件作者声明，并非系统访问限制。** 并非文件或网络沙箱。插件不能通过宿主请求管理员运行，但可自行使用普通用户权限。
4. 修改代码、声明或运行时需重新信任；撤销信任会停用并取消工作。替换版本不继承授权。关键字冲突应改别名或停用冲突包，不会覆盖原手动命令。

## 四个功能入口
- 下载：声明 URL 解析器；默认匹配一个，顶层同优先级冲突明确报错。管理页可按域名配置准确 handler 引用的有序链，最多8阶段；禁用或缺失阶段不会被悄悄跳过。下载任务原有菜单提供手动扩展动作。
- 速启：声明关键字命令／搜索提供者；普通查询提供者还需单独选择加入。晚到结果不抢走已选条目，旧查询结果不能执行。插件结果无管理员执行按钮。
- 剪切板：选中历史条目菜单提供扩展动作；宿主可读取有界文本／文件／图片尺寸快照、创建派生条目或走原生复制完成回执。原条目不因失败被替换。图片读取接口暂不提供。
- 工具：已启用且受信任的命名动作通过统一运行时执行。可以取消正在执行的手动动作。

## 自动事件与设置
- 下载创建／完成／失败、剪切板提交事件分别默认关闭，启用插件不自动订阅；事件只在原功能成功提交后发出，不来自指针／渲染／字节进度。
- 一分钟内三次失败暂停该 handler；管理页显示原因并允许“重试自动事件”。恢复只等待新提交事件，不重放旧事件，也不修改信任／启用／订阅设置。
- 文本、开关、整数范围、单选、文件、文件夹及密码使用明确“保存／取消”。密码为空表示不改，显式清除才删除；密码不写入普通配置。Windows 通用凭据上限2560字节，不能按32KiB传输上限理解为存储容量。

## 下载确认与失败
探测结果保存原始／有效请求、阶段与短期宿主回执。确认后保存目录、文件名、分类、计划、速率等选项可调整而不重复解析；修改 URL／凭据／TLS 必须重新探测。过期／撤销／不存在回执明确要求重试，不暗中重跑插件。解析失败可明确重新探测或选择原始链接绕过，不自动尝试另一组脚本。已接受任务使用持久化有效请求继续／恢复，不依赖插件重复解析每个分段。

## 作者入口与验证范围
参见 `docs/extensions/PROTOCOL.md` 和 `docs/extensions/examples/`：JSON、Python、Node、Windows PowerShell/pwsh 示例是实际夹具输入，EXE 使用相同 JSONL。运行时不自动下载解释器，也不强制绕过 PowerShell 执行策略。
