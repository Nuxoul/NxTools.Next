- Downloads keeps current official menu, normal actions first; extension submenu is after ordinary operations and before destructive commands. Direct leaf execution checks current eligibility; no intermediate chooser. Clipboard uses the same available-action projection and direct dispatch with weak origin/session/window.
- Manual feedback: original bounded ManualRun/host effects remain. For Clipboard use compact same-panel status/actions instead of automatic large Dialog; expanded details remain explicit. Completion does not copy/paste/show another panel. Manager invocation details use content-driven layout/max-height without repeated explanation Accordion. - Catalog cells retain official ListItem/Icon/Label/Tag/Button/Default themes and original fonts, but remove252px forced minimum and stretched filler. No table/list substitution or palette/font fork.
- Example packages under docs/extensions/examples, stdlib Python and actual JSONL contracts only: configurable public GitHub URL prefix resolver (no HTTP/private tokens), explicit download link list action, selected-text transforms. Validate URL/protocol/budgets, no credential forwarding/replay. Tests use owned in-memory/temporary subprocess fixtures; managed trust/install remains independent.

## Design direction
A compact Windows productivity utility: selection -> menu leaf -> inline running/outcome, not selection -> modal chooser -> modal report. Default Kit semantic palette and existing CJK fonts unchanged. Normal action order matches usage; explanatory/technical text is secondary and optional. Initial qualitative UX estimate5/10 for affected flows (judgment, not measured user score): major modal/context/overflow issues; visual density6/10 with forced sizing. Do not invent a10/10 acceptance score from code/tests.
