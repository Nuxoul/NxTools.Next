# Extension purpose and clipboard action feedback

## Approved scope
User approved the audited first slice on 2026-10-15: explain existing plugin purpose and trigger modes for all packages; complete the clipboard manual-action journey before adapting all search/download/automatic feedback. Implementation approved after the explicit confirmation. No installer, deployment, real user plugins or clipboard mutation.

## Requirements
- Overview displays available purpose, human-readable trigger/use instructions and readiness, without inventing author information.
- Detail begins with usage while retaining all existing trust, environment, settings, commands and automation controls.
- A manual clipboard invocation has named per-run accepted/running, terminal/no-change/not-applicable, failed/cancelled/unknown feedback at its originating window.
- Each invocation can be cancelled separately. Closing feedback is presentation-only; cancellation is not rollback.
- Only host-confirmed derived-history item IDs become actionable results. Plugin-reported text is bounded, labelled as plugin-provided and never diagnostic telemetry. Unknown effects are not described as rolled back.
- Explicit View result resolves the actual history item through the sole worker and original history list/query owner, including duplicate revival and items outside the first page. No automatic clipboard copy, focus stealing or script retry.
- Keep bounded session-only recent activity without private payloads or another database.
- Preserve ordinary-user whole-plugin trust, current identity, resource limits, original menu/window/native owners and deferred cross-entity boundaries.
- Correct stale example installation instructions.

## Acceptance
Production-boundary regressions exercise source-only selection, immediate/late completion, parallel isolation, per-run cancellation, verified result identity, locating a persisted result outside page one, closed/reopened origin and no native copy dispatch. Actual current-frame minimum/default light/dark rendering and actionable hit bounds are reviewed separately from compiled tests. Test data/config/SQLite/processes remain owned fixtures.

## Exclusions and evidence limits
No engine rewrite, persistent activity store, automatic replay, permission sandbox claim, W10, dependencies, packaging/install/service actions or installed-user acceptance. Complete feedback adaptations for automatic events/search/download are later slices, not certified by clipboard tests.
