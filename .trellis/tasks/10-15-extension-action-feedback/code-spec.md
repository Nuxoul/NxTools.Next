## 1. Scope / Trigger
Manual extension UI, per-run cancellation/effect feedback, Clipboard result navigation, and package usage projections.
## 2. Signatures
`ExtensionApplication::start_manual(...) -> Result<Uuid, &'static str>`; `cancel_manual_run(Uuid, Context)`; `manual_run(Uuid)`; `ManualEffects::{begin,committed,items,remove}`; `ClipboardHistory::page_containing_item(item_id, limit) -> Result<(usize, ClipboardHistoryPage)>`; `ClipboardPanel::locate_extension_result(session,correlation,item,window,cx)`.
## 3. Contracts
Install pending before dispatch. Bounded ledger32completed/4pending, effect IDs<=64/run,4admitted writes; permits live through actual commit reply. Exact host correlation/package/handler/hash gates effect observations. Completion/cancel is not rollback/cleanup. Weak panel/session/window/query identity checked at explicit navigation/application; no native copy/paste or automatic opening/replay. Original pin/usage/capture/ID order and bounded payload, SQLite count/page snapshot. Narrative purpose is author declaration, not inferred capability. Input state `set_value` in released Kit is silent and does not emit Change.
## 4. Validation / Error Matrix
Untrusted/disabled/missinghandler/service/full -> local reject. Matching terminal once -> per-run state; duplicate terminal ignored. Late committed effect after cancel -> saved evidence may still appear. Closed/stale query/session -> no selection/focus change. Missing/deleted result -> explicit unavailable without replay. Dialog Escape -> Dialog closes, panel stays. No log input/output/name/path/credential payload.
## 5. Good / Base / Bad
Good: old result ID outside page1 located explicitly with original order. Base: unchanged input returns NotHandled with labelled plugin explanation. Bad: script-returned ID trusted, cancel drains pending, one shared status replaces concurrent runs, Dialog and panel both close on Escape, View Result opens/copies unexpectedly.
