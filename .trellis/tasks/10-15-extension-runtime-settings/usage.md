# 扩展运行环境

1. 左侧工作区选择“扩展”，点击顶部“运行环境”。
2. 为 Python、Node.js、Windows PowerShell 或 PowerShell7/pwsh 输入解释器 EXE 完整路径，或点击“浏览”。已有 Python 虚拟环境可选择其 `Scripts\python.exe`。
3. “检测”只运行固定版本参数，显示可用版本或错误；不执行插件，不安装解释器/依赖。检测结果不是信任授权。
4. “保存运行环境”落盘；“取消”不保存。内容较多时滚动，底部按钮始终保留。原生文件对话框使用其自身取消按钮。
5. 单个扩展点击“管理” -> “运行环境” -> “编辑运行环境”，选择继承默认或单独设置。EXE 扩展使用包内文件，声明式扩展无需解释器。
6. 更换有效解释器会撤销受影响扩展的信任并停用；回到“信任与启用”检查来源和权限声明，单独确认信任，再单独启用。
