# Clipboard interaction feedback

## Approved request
The user reports unusable shortcuts and rejects the duration-menu pause interaction. Recording must show one pause icon at the extreme top-right of Clipboard; one click pauses and switches to play, another resumes, without a duration picker. Text preview defaults to rendered Markdown, with no Auto/Language click prerequisite. History text entries also render Markdown. Thumbnails and lightweight summaries remain performance work, not a promised conspicuous visual effect.

## Acceptance
- Production key/focus dispatch regression asserts the exact immutable item and typed paste command, not an arbitrary platform envelope. Page navigation works from history focus. Retain IME, overlay, editor, pending, generation and repeat protection.
- Single official icon Button at top-right; no pause Popover. Pending blocks duplicates. Failed native application stays explicit and retryable. Native ACK/privacy/reconnect behavior remains owned by existing application.
- Default preview renders ordinary Markdown including italic, inline code, one list item, and numbered lists without any control click. Source/code inspection may remain optional, not prerequisites.
- Bounded safe Markdown in text rows; no implicit resources/active links, no stored/native payload changes, no per-frame parsing, no new list controller.
- Relevant source/compiled checks; report physical/native/installed/visual acceptance separately.

## Exclusions
No delegation, packaging, installation, product/service launch, live clipboard/config/history operations, framework upgrades, extra dependencies, unrelated dirty-tree changes, commits or task archive.
