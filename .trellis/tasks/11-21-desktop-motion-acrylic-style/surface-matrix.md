# 磨砂亚克力表面矩阵

回答"哪里是亚克力、哪里不是"。窗口底色（Root）与原生模糊构成唯一的材质；其他角色只是其上的覆盖层，按组合覆盖率设计，实现见 `rust/apps/nxtools-desktop/src/theme/material.rs`。覆盖率为默认值（窗口底色72%、内容层84%）。

| 表面 | 是否亚克力 | 组合覆盖率 | 说明 |
| --- | --- | --- | --- |
| 窗口底层（Root） | 是：原生模糊 + 调色板色 tint | 72% | 页面空白区直接露出模糊桌面；唯一的实时材质 |
| 标题栏、侧栏、标签栏、状态栏 | 是：面板 | 84% | 比底层略实，露出模糊色彩 |
| 列表、表格主体 | 是：面板 | 84% | 同上 |
| 列表头、表头、表尾 | 部分 | 约88% | 略实，标出结构 |
| 分组卡片、折叠 | 否（较实） | 约90% | 相对底层提亮，承载设置项文字 |
| 输入框、选择器 | 否（实底） | 约93% | 状态不依赖背景 |
| 菜单、浮层、对话框、通知 | 否（实底） | ≥97% | 不叠加第二层模糊 |
| Markdown 阅读面 | 否（接近实底） | ≥90% | 长文阅读 |
| 透明宿主（选取叠层、不可见输入窗口、悬浮助手） | 不套材质 | 0% | 保留各自原生目的 |
| 回退（系统关闭透明、高对比、省电、远程、不支持） | 实底 | 100% | 仍是亚克力主题的层级，不切回现有风格 |

## 可读性保证

调色板只决定色相。正文、次要文字、标签与分割线在每个面板/卡片上，于10%和90%灰度桌面（设计桌面）上分别保证4.5:1、3.5:1与1.35:1；不足时沿调色板自身前景色加深，回归测试覆盖全部配色、浅/深色及滑块最小/默认/最大。纯黑纯白壁纸不在保证范围内。滑块下限为60%，以保证上述承诺。

## 展示与动效

- 窗口每次由隐藏变为可见时先保持实底90ms（DWM 建立模糊的时间），再用140ms ease-out 过渡到磨砂；桌面背景文字不会在模糊就绪前透出。减少动态效果时只保留保持段，不插值。
- 主窗口切换模块时内容淡入一次（120ms）；导航、标题、滚动锚点稳定，同一模块重绘不重放。
- 窗口圆角见 [corner-native.md](corner-native.md)：GPUI 绘制的 UnderBorder 轮廓，C# 区域仅裁掉模糊在方角的露出。
