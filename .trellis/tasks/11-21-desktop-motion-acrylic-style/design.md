# Motion and material design

## Material system

参考：[reference-acrylic.png](reference-acrylic.png)。

主题选择为“现有主题 / 磨砂亚克力主题”，配色、深浅色和字体独立保留。主题决定全软件的表面、材质、边界、阴影及状态层级；配色为这些语义角色提供颜色，不代替主题。

| 层级 | 现有主题 | 磨砂亚克力主题 |
| --- | --- | --- |
| 窗口底层/外壳 | 当前视觉规则 | 原生背景柔化 + 随独立配色变化的低饱和 tint |
| 常驻正文、表格、编辑器 | 当前内容层级 | 由新主题统一定义的较实阅读层，不让桌面文字干扰正文 |
| 输入框、选中项 | 官方组件的既有层级 | 比底层更实，状态不依赖背景内容 |
| 浮层/菜单 | 原官方层级 | 新主题统一的浮层实度、边界和阴影，不叠加多层实时 blur |
| 边界/阴影 | 官方组件 + 已认可外壳边缘 | 细边界、短而轻的阴影，不添加发光边或双重外框 |

沿用当前设置的保存/应用边界。切换整套主题不重置明确保存的配色和字体；两套主题均响应独立配色和深浅色选择。参考图中的蓝紫色是配色参考，不是亚克力主题唯一允许的颜色。

只模糊背景，不降低整个窗口的 opacity；文字和图标不随材质变淡。不从静态截图推算“精确透明度”或承诺同一 blur 半径跨系统一致。

不可用、用户关闭系统透明效果或进入需要回退的环境时，亚克力主题显示自己的实底回退层级，保留该主题的边界、阴影和状态规则，不切回现有主题。减少动态效果与透明设置是不同偏好，不相互替代。当前 GPUI accent 调用未证明具备 WinUI 的完整自适应行为，产品须明确解析实际能力与系统事实。

## Whole-app coverage

主窗口和各模块、全局及功能设置、工具窗口、快捷启动、剪切板、压缩包浏览器、Markdown、扩展 Sheet/Dialog、菜单、辅助预览、通知和 About 均使用所选主题。

同一主题角色映射到官方组件公开样式和窗口底层；不用不同模块各自维护一套颜色/材质分支。已有窗口下一应用轮统一更新，新建或复用窗口读取相同主题状态。保留原输入实体、草稿、焦点、滚动、任务和会话身份。

完整主题不意味着每个子控件分别模糊：共享窗口底层提供材质，内容层使用主题统一的实度。被动预览等特殊原生表面遵循相同视觉体系并保持原生命周期。

## Corner integration

用户认可的 UnderBorder 外观用于快捷启动和剪切板的目标外壳。现有证据来自独立示例中不透明填充、1px 实线、8 DIP 圆角及 100% DPI，不覆盖任意半透明组件。

保留 source-over 前提和原 SDF 覆盖；在同一绘制轮廓中处理背景/边框重复覆盖。材质背景、透明 gutter、HRGN 命中区域、原生阴影必须联合验证，不直接复制示例到所有组件。原正式依赖锁定和补丁范围如需调整，写入获批实施计划后再动手。

## Motion grammar

- 反馈紧随操作，不延迟实际提交、粘贴、搜索或窗口激活。
- 只动画内容层，不插值 HWND bounds，也不整体缩放文字。
- 新状态使用原业务身份/代数触发一次；普通重绘、缓存命中、虚拟滚动和同一结果刷新不重播。
- 通用候选：120ms ease-out，必要时 2–4 DIP 内容归位；较大窗内展开 160ms。现有官方组件时序不因这两个候选值而自动改写。
- hover/pressed/focus 使用官方状态，不给每个控件增加独立 tween。
- 真实忙碌状态可使用原 Progress/Spinner；静止界面没有装饰性时钟。
- 减少动态效果直接显示结果，不创建零时长动画或展示用帧循环；输入、取消及代数规则不变。

## Surface matrix

| 表面 | 当前行为 | 本轮设计方向 |
| --- | --- | --- |
| 主窗口导航/设置 | 直接切换模块；原草稿/保存边界 | 仅候选 120ms 内容淡入，导航、标题与滚动锚点稳定；不做整页滑行 |
| 快捷启动结果 | 120ms、按结果身份一次入场 | 优先现有 Fade/None；保留现有用户配置，不叠加第二层行入场 |
| 快捷启动/剪切板外壳 | 原原生准备/展示状态机 | 最终 bounds 后，最多一次轻量内容出现；输入当即可用，退出不拖延取消 |
| 被动预览 | Quick 130/90ms；Clipboard 130ms 入场 | 保留 generation 和被动性；新内容出现，不让旧内容重新变得可操作 |
| 下载探测/阶段 | 120ms；任务栏 90/120ms | 原位置原几何转态；进度不逐 tick 补间、数字不翻牌 |
| 压缩包/Markdown | 原预览/纲要状态机；纲要 160ms | 原布局/焦点/取消者；修正标题定位高亮的减少动态效果缺口 |
| 扩展 Sheet/Dialog | 官方 150/250ms 等 | 保留官方组件及 modal/focus，不另造过场控制器 |
| 通知 | 官方 400/200ms 和原队列 | 保留官方单一时钟、暂停和关闭；不添加第二次出现效果 |
| About | 原页面淡入/有限指针反馈 | 不扩大徽标动效，不增加 idle 动画 |

## Stageshow storyboard

交付形式：整套主题静态总览，加可分别查看的三个短动效场景，用户点击播放。总览覆盖主窗口、设置、工具和辅助表面的共同主题角色；短场景表达代表性交互，不限制产品覆盖。每段只有一个操作原因和一个明确结果。大尺寸约 960×560；358px compact 版本重排为局部特写，不缩小整窗。

沿用 NxTools 名称、Windows 窗口控制、Sarasa 字体和真实控制层级。参考图中的 macOS 三色按钮不是产品需求。每帧保留足以辨认的原界面上下文，焦点文字不超过 3–7 处，不用空卡片或骨架条充数。

### 1. 快捷启动：输入到结果

- 起始：磨砂搜索面板已经处于稳定最终位置。
- 输入：光标位于原搜索框，输入一个虚构的非敏感示例词。
- 结果：显示三条稳定结果，一条选中；只让新结果做一次 120ms 轻淡入。
- 停留：保持最终结果作为 poster；关闭由明确 Escape 原因触发，不无故倒放数据。

### 2. 剪切板：选择到预览

- 起始：有内容的列表和固定搜索栏，使用编造的短文本，不读取真实剪切板。
- 选择：光标移动到示例记录；保留现有 800ms hover 意图延迟。
- 预览：同一辅助面板显示预览，130ms 轻归位；主面板、文字与光标不跳动。
- 停留：选中记录与预览共同构成 poster。退出由移出明确触发，窗口被动性由后续原生验证，不从演示认证。

### 3. 全局设置：切换整套主题

- 起始：真实设置分组构图，主题选择与配色选择分开。
- 操作：选择“磨砂亚克力主题”，通过原保存/应用动作统一应用；不伪造当前设置为即时持久化。
- 结果：主窗口、设置和同场辅助窗口使用同一新主题；保留原配色，外壳透入柔和背景色，输入和正文呈现新主题的较实层级，没有持续动态背景。
- 停留：跨窗口一致的主题层级作为 poster；减少动态效果版本直接呈现同一最终帧。

## Demo acceptance

从 stageshow `panel-annotation`/`overlap` gold 的构图和 `raycast` 的搜索交互取起点，使用其 Stage/Window/Row/Field 等公开部件，改成 NxTools 视觉，不复制其他产品身份。

演示需在大/compact 两种宽度检查 still、完整时序、按压/预览/关闭节点及循环边界，运行 film rehearsal gate。CSS backdrop-filter 只用于视觉表达，不进入产品或资源测试结果。
