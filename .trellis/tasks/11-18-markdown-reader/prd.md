# Markdown Reader

## Goal

Add a standalone Markdown tool to NxTools Other Tools. Make local documents easy to read, edit, share and recover without leaving NxTools or installing mdview. The window opens in Preview.

## Requirements

- **R1 — Reading.** Open `.md` and `.markdown` from the reader's file chooser, a file drop, or the entry points in R5. Work in one resizable window with multiple tabs; reopening an already open file focuses its tab. Keep the reading position per tab. Render GFM prose, tables, highlighted fenced code, local relative images and document links. Use a Winc-style left outline rail: follow the visible section, reveal the hierarchy on delayed hover or keyboard activation, and support pinning with an overlay fallback at narrow widths. Clicking the collapsed marks does not toggle the card. Keep single-line, non-overlapping rows, full headings available on hover, and section navigation by source identity. Provide `Ctrl+F` over rendered text with next/previous matches, font and column width controls, and NxTools Light/Dark/System theming. Refresh after external saves; recoverable read errors retain the last good document and show how to retry.
- **R2 — Editing.** Keep three mutually exclusive header choices **「代码」**, **「分栏」** and **「预览」**. Code edits syntax-colored Markdown source; Split shows the same source beside the read-only live preview, synchronized by document position. Preview is always read-only; editing belongs to Code and Split. No F2/F3 mode shortcuts; ordinary keyboard navigation and activation remain. `Ctrl+S` saves the draft, while mode changes never save. Mode/tab changes preserve drafts and reading location; Code/Split share source undo. Conflict, failed save and canceled close never discard a draft or silently overwrite an external change.
- **R3 — Export.** The current document can be explicitly exported to single-file HTML or PDF. HTML keeps formatted content, an outline and supported local images in an offline-openable file. PDF uses paginated document layout with selectable, searchable text. Export never saves or changes the `.md` document. A canceled or failed export does not replace an existing output or leave a partial output at the selected path.
- **R4 — Version history.** Automatically keep distinct committed versions locally on file open, successful save and observed external save. Show a timeline, allow naming versions, and compare a version with the current saved file or another version. Restore is explicit, preserves the exact historical file bytes and first retains a recoverable copy of the current committed version. A dirty or conflicted draft is not silently discarded. History survives closing NxTools and is never sent to a server.
- **R5 — Tool settings and Explorer entry.** Match the existing Other Tools tile: icon, name, truthful enabled/disabled status and a **「配置…」** action. Open the same style of feature settings window, with an enable switch, default outline visibility, font size and body width, and a secondary **「打开预览…」** action. Offer explicit `.md` and `.markdown` registration, show the actual Windows handler status per extension, and guide the user through the Windows default-app selection. After NxTools is chosen in Windows, an Explorer double-click opens that document directly in reading mode without opening the main NxTools window or the settings window. Keep existing tabs and drafts when disabling stops new opens. If a selected extension still defaults to NxTools, guide the user to change the Windows default before disabling the feature or removing its registration.
- **R6 — Winc Markdown presentation.** Use the supplied `INSTALL.md`, outline and typography screenshots as the visual baseline. Keep a compact top strip without an Open button; retain Ctrl+O, drop and Explorer open. Center the article and align typography, tables and chapter marks. Preview and the rendered side of Split have no source line numbers. Hover expands the outline over the marks; the pointer can enter the card, jump without dismissing it and pin it. Keep the existing draft/history/export owners.
  Code uses a single borderless source surface with muted row numbers; the same source surface sits to the left of the read-only pane in Split. Start with two equal panes, retain the dragged proportion while resizing, and reset to equal widths on divider double-click. Keep at least 240 DIP per pane and fall back to a source-only view when the workspace cannot accommodate both panes.
  One reader font size governs source text and preview body text. A−/A+ changes both panes in Split and remains effective in Code and Preview. Heading scales remain relative to body text; font changes preserve the draft and source undo.
  File tabs use the official Kit TabBar/Tab appearance and close slot, retaining deduplication, dirty status, selection and close confirmation. Use official tab scrolling rather than a redundant file-list dropdown beside a single tab.
- **R7 — Foreground Explorer open.** A user-initiated `.md`/`.markdown` double-click restores and foregrounds the Markdown reader and selects the requested document, including cold start, protected redirect, reuse behind another application, and reuse while minimized. Do not summon the main window, duplicate tabs, toggle an always-on-top style, or treat IPC admission as successful activation.

## Acceptance Criteria

- [ ] **R1:** Open and drop two Markdown files; reopening one keeps a single tab for it. Tab switching preserves scroll position. A fixture with long Chinese headings, nested and duplicate headings, a relative image, a table and fenced code renders correctly. The outline follows the viewport, keeps the selected target until independent scroll, shows the last visible section at the end, and jumps to the correct duplicate heading. At narrow and wide widths, verify hover, click, keyboard, pin and the narrow overlay fallback. Recognized fenced code shows distinct token colors in Light and Dark; unrecognized and unlabelled fences remain readable and copyable. `Ctrl+F` reaches matching blocks; an external save refreshes the document without losing the reader's place. Canceling the chooser leaves the current document unchanged.
- [ ] **R2:** Verify all three choices at minimum size in Light/Dark, pointer and keyboard activation, and no F2/F3 switching. Preview never exposes an editing command or edits on body input. Source highlighting has actual token colors. Split scrolling follows source locations in both directions without feedback. Mode changes preserve drafts, reading location and undo; saves preserve original bytes when unchanged; failed writes, canceled close and external changes retain the draft. Native caption drag and window controls still work.
- [ ] **R3:** A document with Chinese text, a table, code and a local image exports to self-contained HTML that renders with no network and a multi-page PDF with searchable text. A selected unsaved draft can be exported without changing the source or marking it saved. Save-dialog cancellation, a locked output, and unavailable PDF runtime leave source and existing output unchanged and provide distinct feedback.
- [ ] **R4:** Initial open, a changed save and an external revision produce distinct timeline entries; unchanged operations do not create duplicates. Versions can be named and compared after restarting. Restoring an earlier version yields its exact bytes and the version from immediately before restoration is still recoverable. A failed restore leaves the original file intact and reports failure.
- [ ] **R5:** The tool card aligns with adjacent tools and clicking **「配置…」** opens or focuses one settings window, without launching the reader or toggling enablement. Saved activation and reading defaults survive restart; failed saves preserve the previous applied state. Registering NxTools leaves any previous Windows default unchanged; after the user selects NxTools for an extension, the setting reflects the real default. Double-click a path containing Chinese and spaces in Explorer with NxTools closed and running: show the target document directly, reuse the reader when running, and deduplicate repeated opens. Unregister only NxTools' values and never leave an effective default pointing at a removed handler.
  Settings save and explicit association results use the existing application notification system, bound to the originating settings window. Automatic association queries stay silent. No inline result banner or settings-row movement; failed saves retain the previous applied preferences, and duplicate/superseded replies do not notify twice.
- [ ] **R6:** Compare the actual Winc and NxTools article, compact header, tables, inline code and fences under matched viewport and theme. Verify no Open button or source line gutter in ordinary Preview, document-relative marks, 200 ms hover dwell, card anchored over the marks, continued hover across the card, jump without dismissal, independent-scroll tracking, fade on leave, and pin/unpin with narrow fallback. Check Winc-style heading feedback as well as keyboard reachability. Inspect actual images, not only geometry or syntax-color tests.
  Clicking an outline entry and releasing the button must not make later pointer motion into prose extend a selection. Ordinary pressed text dragging remains available before and after navigation in Preview and Split.
  Compare Code and Split on the same `INSTALL.md` in Light and Dark. Check equal source/body font size and real A−/A+ effects in all modes, absence of a Preview edit command and redundant single-tab menu, borderless source with row numbers, equal initial panes, divider drag/reset, minimum-width fallback, and preserved draft/caret/undo/scroll synchronization.
- [ ] **R7:** Reproduce and then verify a real Explorer double-click with the Desktop closed, open behind Explorer, and minimized; exercise the installed forwarding/redirect path when it applies. Require `GetForegroundWindow()` to identify the reader HWND and the expected file to be selected. Repeat the same file without creating another tab; keep unrelated windows, user defaults and Archive intake unchanged.

## Scope boundaries

Windows desktop only; association registration is user-initiated and limited to Markdown. Do not silently take over the Windows default or change existing archive associations. No new cloud/library service, external-editor integration, attachment pasting, publication templates, Mermaid/KaTeX/mind-map parity, or licensing/paid-feature replication. No changes to Clipboard, Quick Launch or Archive Markdown previews. Package, installation and machine-wide association changes are outside this scope.
