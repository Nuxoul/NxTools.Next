## Invariants / red-capable regression plan
- All custom palette reads occur at the current render/content callback; cached Theme is local presentation state only. Global observers retain one keyed Subscription per entity/window, notify a weak view on the next App turn, and do not update feature/application owners synchronously.
- Existing input entities, task IDs/generations, HWNDs, bounds, pointer gestures, pending results, native show/hide/passive/activation policies and user drafts stay unchanged. Theme repaint never reopens a window, releases an image or replays an enter generation.
- Verify production scenes via `Window::painted_quads`, not token equality alone. Taskbar regression must detect opaque full-client Root fill while preserving real progress paint and bounds; tests use synthetic data/disconnected bridge only.
- Actual DWM/native external-client composition and mixed-DPI remain deferred without an authorized isolated HWND pixel-readback run. A source fix or GPUI scene regression is not compositor acceptance.
