## Source state and interfaces

- `formats/xz.rs::list`: preventive structural/allocation admission, one immutable session/ordinal entry, safe derived filename through existing path policy, actual compressed length and unknown expanded size (`None`). Index declarations are not advertised as verified payload sizes. Method `0x21` denotes the terminal LZMA2 filter, not a ZIP method number.
- `formats/xz.rs::extract`: existing protected ArchiveOutput partial, fixed 64KiB writes, all-stream integrity and actual-byte limits, original-source revision check, cancellation checkpoint, then commit. Errors abort only this token; already published/unrelated outputs are retained.
- `formats/tgz.rs::{matches_xz,decode_xz}`: `.tar.xz`/case-insensitive `.txz`, gated by XZ signature plus structural and actual TAR validity. Anonymous exclusive delete-on-close disk spool completes outer integrity before inner metadata or ANY native target output. Spool uses total output budget; TAR files retain individual-entry budget. TAR extraction rechecks the original compressed source, not the spool.
- `engine.rs`: six-byte XZ signature; Xz/TarXz open and real test/extract capabilities, standalone unknown-size exception and streaming test, TarXz full-outer decode before existing TAR test/extract. No duplicate worker dispatch, Zstd advertisement, creation rewrite or native publication change.
- Decoder errors: locked0.21.0 `error_other` also denotes invalid LZMA data. Controlled source reads tag real I/O/OutOfMemory before codec entry and preserve already typed ArchiveError; decoder Other then maps to CorruptArchive without text matching. Unit regression preserves cancellation/resource/I/O. Padding scans check cancellation too.
