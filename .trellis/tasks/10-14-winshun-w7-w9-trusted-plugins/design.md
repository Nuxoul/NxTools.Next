# W7/W8/W9 design

Canonical approved contracts, defaults, schemas and first-release operation matrix: ../10-14-winshun-w6-w9/design.md. This child integrates execution and feature Adapters; implementation and joint verification are active.

## Runtime / protocol
Reuse W6 package/catalog/content identity. Rust invocation state registers pending before C# dispatch. Dedicated demand-start `--extension-host` PlatformHost mode owns non-elevated native process/credential work with current-user authenticated transport and parent process lease; no service/hooks/tray or elevated helper reuse. Each plugin runs once, suspend->Job configuration/assignment/token check->resume, explicit argv/stdio handle allowlist; EOF/deadline/overflow/revoke/disconnect retire and cleanup bounded ordinary tree. Native output pumps and cleanup outside serial control reader; whole-chain state in Rust. Main C# mode separation is a required actual fixture, not inferred from build.

Duplex UTF8 JSONL invoke, result_batch, host_call/result, complete, cancel; per-frame/run budgets and stable request/run/call/sequence IDs. A plugin can call advertised typed host operations while running, but feature Adapters remain state owners. Nested downloads/clipboard work is deferred, causal and bounded; recursive call to same resolver cannot deadlock behind its own per-plugin slot and is rejected with fixed re-entry error. No interpreter fetch or cmd string concatenation. Missing executable/policy error retains request and gives actionable fixed status.

## Feature integration
- Download common injected interface resolves before probe/acceptance and before scheduler lock; durable duplicate receipt checked first. GUI/background initialize same Adapter; CLI stays a pipe caller. Probe resolution receipt is host-bound to original/effective/trust/settings/expiry identity; transformed input does not loop or leak headers across origins. Single routing and user-configured <=8 stage chains, failure-stop/explicit bypass, root correlation/whole-chain deadline. Existing task validation/HTTP/network/media/TLS/schedule/storage/idempotency preserved.
- Download committed lifecycle events subscribe at engine composition and do not block original publisher; post-finalization events do not imply progress ticks or GUI-only support.
- Clipboard worker returns committed stable item identity only after persistence succeeds, then bounded event dispatch off worker/leased callback. Selected content action and derived entry/copy effect reuse history/native owner. Failed captures no event; old items remain on transform failure. Host-managed causality/suppression prevents loop, rate/circuit handles uncontrolled external write bursts without claiming full attribution.
- Finder/QuickLaunch keyword/ordinary providers use stable namespaced rows and parent quotas. Old generations/content/trust never publish or execute. Same-ID in-place update preserves selected row; late new rows do not displace committed selection. UI callbacks only local writes then next-turn application work; W5/IME intact.
- Tools named actions and notifications expose existing shell/clipboard/download operations; no arbitrary plugin panel/HWND injection. All operations advertise version/headless availability and return explicit unsupported/ui-unavailable errors.

## UI / secrets
Tools shared manager has explicit module/permission declaration, trust/enablement/event/chain/effective-budget/runtime/error states. Official0.7.1 Settings public slots and Form fields/Alert/DescriptionList/ListItem, not a new UI framework. Preserve original main/native/client budgets and feature input identities. Credentials use user/package/setting targets and compensated attempted-write transaction coupled with nonsecret config commit; testing uses injectable isolated store and never logs data. Changed content/declaration invalidates trust and queued/active runs before publication.

## Compatibility and verification
Default empty registry = unchanged feature behavior/no broker. Old tasks/config decode additions default absent/empty; no rerun of site parsers for old accepted tasks. Blob import/media tracks/resume validators continue original paths. Protocol example scripts/fixtures cover all runtimes available; no interpreter availability fabricated as PASS. Synthetic EXE protocol fixture ensures base runtime behavior even when optional interpreters absent; requested four-runtime support requires actual available fixture coverage or explicit blocker. Parent full checks and single optional final review apply; no independent review loop.
