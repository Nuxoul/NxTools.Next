## Preserved invariants

Native complete source ownership precedes all reads; immutable operation/entry/source revision and password-session identity remain authoritative. Format CRC/authentication and declared/actual resource limits precede output completion. Ordinary extraction uses original final-name capabilities and incomplete-only cleanup. Create retains verified candidates and new-family no-replace publication; no set-wide atomicity or blanket rollback claim.

All entity callbacks update local state first; cross-entity/native effects defer to the next application turn. Existing window bounds, Root lifetime, close/Escape/focus and original form/InputState/menu/Job owners remain. Any UI addition records released component API/slot/variant/size and parent adaptation before code, then tests actual production interactions. Screenshots and synthetic actions do not accept physical UI.

No names, paths, passwords, comments, payloads or per-member/byte-tick logging.
