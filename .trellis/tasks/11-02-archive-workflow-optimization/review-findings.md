# Archive optimization — findings, reference mechanisms and change locations

## Decision

The existing architecture is suitable. The primary costs are repeated whole-source admission, per-member drag attempts, duplicate ZIP payload verification and text-encoded synchronous bulk transfer. The primary workflow gaps are hidden background decisions, invalid queued controls, incoming Add collisions, incomplete intake/results and missing creation coverage. Editing progress has a concrete cross-language contract mismatch. Creation also lacks an authoritative result-location route.

The [coverage map](D:/Code/NxTools.Next-main/.trellis/tasks/11-02-archive-workflow-optimization/requirements-map.md) assigns every finding/preservation row to a requirement, priority, OPT package and G gate. **Defect** means a current supported path fails its intended behavior; **optimization** means demonstrable duplicate work; **required enhancement** means scheduled behavior not yet present; **preserve** means no defect is asserted. No static finding here is a runtime test result.
