## Ownership and dependency seam
Extensions owns strict origin declarations/canonical bytes, immutable invocation context, method discovery/requirements/current identity/deadline and original BlobRun resource lifecycle. Desktop owns HTTP consumer/client operation and injects original shared NetworkPolicy in GUI/headless ExtensionService composition. NetworkPolicy owns only immutable route snapshot/client construction, Core owns persisted network settings, GPUI only existing trust-details rendering. `nxtools-network -> Core -> Extensions` already exists; never add reverse Extensions->Network/Core dependency. Use existing Desktop reqwest/Network dependencies instead of a new cross-layer cycle.

Original runtime pending/current checks must surround host admission and reply; redirect/body continuation checks cancellation/current invocation. Do not export a general package registry/entity/native/file handle. The exact minimal host-issued immutable origin/deadline/budget context and BlobRun host-sealed-body seam must be grounded in current constructors before code changes. Avoid a global perrun value cache or another protocol reader. At most2concurrent network operations perrun/4global and16MiBactual decoded networkIO use finite resource ownership associated with actual active invocations, not unbounded caller IDs. Completed operations release concurrency, never the invocation's accumulated IO budget; no lifetime2request cap.

## HTTP operation invariants
Validate strict params/body/origin/admission before any network contact. Freeze policy once. Disable client auto redirects/retries and inherited state; explicitly process at most3GET/HEAD redirects with declared origin check/no HTTPS downgrade/header drop on origin change. Non-GET returns status/Location with no request replay. HEAD empty body remains explicit. Preserve HTTP error status responses. Stream within actual body cap and overall/perrun decoded budget into an existing registered host blob resource, then publish immutable sealed descriptor after exact completion; failure retires partial backing and never claims success. Current invocation/time/cancel and blob IO ownership remain held through completion; logical cancel cannot release actual blocking cleanup. No body/header/URL diagnostic payload.
