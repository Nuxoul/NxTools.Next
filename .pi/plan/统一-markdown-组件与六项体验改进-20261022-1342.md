# 统一 Markdown 组件与六项体验改进

## 目标与范围
依据用户粘贴的需求，完成六项工作，不把 Markdown 接入缩减为一个显式编辑窗口：
1. 统一剪贴板列表富文本、剪贴板文本大预览、显式文本编辑和速启文本/Markdown 预览。
2. 修复通知弹出/收回卡顿。
3. 剪贴板设置新增六种图片预览模式，默认“自动”。
4. 速启设置新增连续/分隔列表切换，分隔间隙较剪贴板更小。
5. 排查并修复资源嗅探、探测或代理链路中可证实的慢路径。
6. 重新设计默认明暗配色，保留官方组件和已有可选主题。

当前基线为 GPUI-Kit 0.8.0 / 默认 gpui-pre 0.3.9。保留全部无关脏树和并行 Archive 工作；自行实施，不委派、不联系其他会话。不提交、不归档任务，不打包、不安装、不启动正式产品、不操作服务或真实剪贴板/历史/配置。

## 已核实的关键事实
- 编辑器当前主分支仍为 `31608fa74bdbeca79d9901bf2daa48ea7ecf1ecc`，v0.1.0，实际 Cargo/LICENSE 为 Apache-2.0；依赖与当前框架匹配。
- 编辑器使用 Kit 的 BlockNode 渲染器。`set_readonly(true)`只禁止修改，仍安装输入处理器、注册焦点和点击选择；没有公共的不可聚焦展示开关。因此不能直接放入列表/被动预览。
- 通知 `notifications/screen.rs::open_surface` 使用 `..Default::default()`，继承 GPUI 的 `inactive_frame_interval = Some(33_333μs)`。GPUI `window.rs` 对非活动窗口的动画按此限帧。通知是非激活窗口，剪贴板/速启预览则已显式设为 `None`。这是源码定位，尚未做修复前后的实测。
- 剪贴板图片当前固定约440×340 DIP并完整适应，不具备六种模式；当前放置使用整屏 bounds。
- GPUI Windows `visible_bounds()`实际来自 `MONITORINFO.rcWork`，可沿公共接口取得排除任务栏的工作区，无需新增 C# 命令。
- 速启使用 `uniform_list` 和稳定的结果/选择/预览所有者，目前没有外部条目间隙。
- 下载 `HttpDownloadClient::probe_timed` 同时等待 HEAD 和 Range，两路最长各有探测期限；已有慢 HEAD 测试只验证成功和元数据，没有延迟断言。不能仅凭这点认定它是用户慢资源的唯一原因。
- 下载参考已按要求查看 ABDM HTTP/proxy 和 FluxDown 探测/代理源码；本轮不再查看旧 NxTools 下载源码。FluxDown 仅作 AGPL 行为研究，不复制实现。

## 2. 全面统一 Markdown 文档组件
**文件**：根/Desktop Cargo、Cargo.lock、`main.rs`，新增共享 `ui/markdown_document.rs`及测试；修改 `ui/history.rs`、`ui/preview_rich.rs`、`ui/preview.rs`、`ui/mod.rs`、`ui/search_input.rs`、`quick_launch/preview.rs`及其构造调用点和测试。

### 依赖与最小适配
- 将固定提交的编辑器保存到 `vendor/gpui-kit-markdown-editor-010/`，保留许可证和逐文件来源哈希；通过 workspace 依赖接入。
- 关闭编辑器默认 syntect，不打开其“全部语言”feature；复用项目已有 Tree-sitter 与15种语法，保持同一 Kit/pre 图，不启用 Fast。
- **本计划请求批准编辑器库的一个窄补丁**：在 `src/element.rs` 增加可选被动展示模式。默认交互行为不变；被动模式只复用相同文档投影、Kit 渲染、样式和可见区域裁剪，不安装输入处理器、Tab焦点、编辑动作、光标、表格/代码拖动柄和鼠标编辑处理器，语义为只读文档而非可编辑输入。
- 先写库级和实际宿主回归，再实施补丁。来源门禁限制实际改动文件。现有 GPUI Component/Windows 两处框架补丁不扩展。

### 四个入口
| 入口 | 接入方式 | 必须保留 |
|---|---|---|
| 剪贴板列表文本 | 共享文档组件的被动、无内部滚动展示 | 安全400字符摘要、按条目挂载缓存、整个文本卡≤210 DIP、外部8 DIP间隙、点击/修饰键仍执行原始完整条目 |
| 剪贴板文本大预览 | 相同文档组件，被动、一个受控滚动视口 | 实际内容测量、原文切换、最后内容可达、独立非激活 HWND 与原生 ACK/帧/generation |
| 显式文本编辑 | 相同库的交互 BlockEditor/官方外观组合，必要的原文编辑切换 | 原始完整条目装载、中文 IME、撤销重做、表格/列表/代码、保存/取消/失败保留草稿、返回搜索焦点 |
| 速启文本/Markdown预览 | 相同文档组件；Markdown正常展示、代码和配置按原文代码块展示 | 文件读取预算、截断提示、文件元数据、固定预览窗口/同一选择generation、无文件写回 |

- 源码/代码内容不能被当作 Markdown 改写；原文模式走同一文档展示后端的字面量/代码表示，保持可读的原始内容。
- 替换上述入口原有 TextView 路径，不保留一套未说明的旧富文本渲染器。
- 图片使用 `ImagePolicy::Placeholder`；链接在只读预览不启动浏览器/网络，列表链接区域仍走原条目动作。HTML/资源/超深结构继续通过既有安全预算与降级策略。
- 原始剪贴板文本是独立的不可变动作载荷，不能用400字符摘要或编辑器 canonical Markdown 替代。未修改就保存保持原始字节，取消绝不写；只有明确修改并保存才将编辑结果交给原有历史 worker。原文编辑保持字节语义；富文本保存可规范化格式，明确提示，不静默规范化只读内容。
- 热路径使用修订缓存，不每帧序列化/重新解析；列表只建立已挂载行状态，保留原有有界分页。
- 所有跨实体回调下一应用回合执行，包括缓存命中。搜索回退识别新的实际编辑器焦点，编辑时不能把键盘输入偷回搜索。

## 3. 六种剪贴板图片预览模式
**文件**：Core配置/default/merge测试，`main_window/clipboard_page.rs`和设置测试，`clipboard.rs`、`clipboard_preview_presentation.rs`、`ui/preview.rs`；可新建 `ui/preview_image.rs`承载纯布局算法。

新增 serde-default 枚举 `ClipboardImageViewMode::{Auto,Fit,Panorama,Light,Mini,Compact}`，在剪贴板设置增加官方 Settings/Select 32 DIP“视图模式”及完整说明。沿用该页面现有保存策略和 section-owned merge，失败不发布新值，保留最新存储目录与其他模块设置。

| 模式 | 行为 |
|---|---|
| 自动（默认） | 在沿用的相邻右侧优先/左侧回退位置，利用真实工作区内可用矩形最大化显示；普通比例完整展示，超长/超宽图片保持可读比例并允许溢出轴滚动 |
| 适应 | 始终等比例完整展示全部图片，不创建图片滚动或导航 |
| 全景 | 1源像素对应1设备像素；窗口限制在可用工作区，超出部分横向/纵向滚动 |
| 轻量 | 自动策略，但浮窗短边≤800设备像素 |
| 迷你 | 自动策略，但浮窗短边≤500设备像素 |
| 小巧 | 自动策略，但浮窗短边≤300设备像素 |

- 保持宽高比；800/500/300限制的是浮窗短边而非长边，按实际DPI换算，含边框/元数据预算。普通模式不无谓放大小图片。
- 使用已核实的 `visible_bounds()`与目标DPI，不用整屏覆盖任务栏。不新增预览位置设置，只沿用当前相邻放置规则；优先侧空间不足时回退可用侧并钳制。
- 视口和图片内容尺寸分离，仅真正溢出轴滚动；切换条目/模式重置旧滚动，适应模式不留旧偏移。
- 只复用一个被动预览 HWND，模式变更经原有 generation、隐藏/离屏、最终bounds ACK、帧就绪再展示；旧结果不能覆盖新模式。
- 不改变列表图片190 DIP、文件62 DIP、源图标色、截图/粘贴原图或捕获预算，不因“全景”无限分配位图。

- 先补本地可控的快Range/慢HEAD、慢Range/快HEAD、HEAD独有文件名、redirect、拒绝Range、清单慢响应与取消用例，给已有慢HEAD测试增加真实延迟断言。
- 先用回归复现再比较策略：优先利用可用Range元数据，必要的补充HEAD只能有有界等待；不能简单“第一个返回就赢”而丢失文件名、长度/validator或虚报续传。若需要把非关键HEAD元数据补充从确认主路径分离，明确其截止、用户已编辑文件名保护和generation，不让迟到响应改写已接受请求。
- 系统代理分别验证Direct/System/Manual实际客户端和缓存失效；本地代理必须收到确切请求，不能仅断言配置枚举。检查DNS/连接/首字节/清单时间，保留每次操作的不可变路由，不静默回退Direct、不混路、不关闭TLS校验。
- 不新增FluxDown的自动测速/热切换/PAC/认证功能。系统代理真实Windows命中若无法在不改变系统设置下证明，给出证据范围，不假称已验证。
- 用户未提供具体慢资源：优先定位可复现问题并修复；若本地链路均正常且外部症状仍不可复现，保留低噪阶段诊断并报告所需的脱敏样本，不能凭猜测改全局超时后宣称解决。
